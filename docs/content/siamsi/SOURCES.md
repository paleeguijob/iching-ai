# ที่มาของเนื้อหาเซียมซี

ไฟล์ข้อมูลอยู่ที่ `frontend/core/data/src/commonMain/composeResources/files/siamsi/` (`guanyin100.json`, `jiazi60.json`)

## หลักการ (ตามสเปก 1.4 ข้อ 1.2)
- **กลอนต้นฉบับจีน** (`poem_orig`) เป็นตำราโบราณ ไม่ปรากฏผู้แต่ง จึงคัดมาใช้ได้ เราคัดเฉพาะตัวกลอน เกรด และคู่ก้านกิ่ง
- **ส่วนที่เขียนเองทั้งหมด** ได้แก่ `poem_th`, `summary`, `topics` และ `keywords`
  - ร่างโดย AI (Claude) จากความหมายของกลอนต้นฉบับ ไม่ได้คัดลอกคำแปลหรือคำอธิบายจากหนังสือหรือเว็บใด
  - หัวข้อ `health` ไม่แนะนำวิธีรักษา ใช้แนว "ดูแลตัวเอง ปรึกษาแพทย์เมื่อมีอาการ"
  - ไม่ทำนายเรื่องความตายหรือโรคร้าย
- **`story` (เรื่องในตำนาน / 典故) เว้นว่างไว้ทุกใบ** เพราะแต่ละวัดหรือศาลเจ้าจับคู่เรื่องกับใบไม่ตรงกัน ถ้าใส่ไปจะเป็นการเดาเอง ในแอปเมื่อ `story` ว่าง หัวข้อนี้จะถูกซ่อน

## 觀音靈籤 — เซียมซีเจ้าแม่กวนอิม ๑๐๐ ใบ (`guanyin100`)
- **ฉบับ:** 觀音一百籤 แบบที่ใช้ในวัดกวนอิมไต้หวัน เช่น วัดหลงซาน ไทเป
- **แหล่งที่คัดกลอน (เข้าถึงเมื่อ 9 พ.ย. 2569):**
  - https://temples.tw/stick/fs_yin100 (台灣好廟網)
  - https://qiangua.temple01.com/qianshi.php?t=fs_yin100 (籤卦結緣讚)
- **ตรวจทาน:** ทั้งสองแหล่งตรงกันทุกตัวอักษรครบ ๑๐๐ ใบ ทุกใบมี ๔ วรรค วรรคละ ๗ คำ
- **`grade_orig`:** ใช้ 上 / 中 / 下 ตาม 上籤 / 中籤 / 下籤 ของแหล่งที่สอง แปลงเป็นระดับตาม `gradeToLevel`
  - 上 → ดี (๒๔ ใบ)
  - 中 → ปานกลาง (๕๘ ใบ)
  - 下 → ควรระวัง (๑๘ ใบ)
  - บางฉบับให้ใบที่ ๑ เป็น 上上 แต่เราใช้ตามแหล่งที่คัดมา

## 六十甲子籤 — เซียมซีหกสิบกะจื๊อ ๖๐ ใบ (`jiazi60`)
- **ฉบับ:** 六十甲子籤 แบบที่ศาลเจ้าแม่ทับทิม (媽祖) และศาลเจ้าจีนใช้ ลำดับ 甲子 → 癸亥 ไม่รวม 籤頭 / 籤首 / 籤王
- **แหล่งที่คัดกลอน (เข้าถึงเมื่อ 9 พ.ย. 2569):**
  - https://temples.tw/stick/fs60 (台灣好廟網)
  - https://qiangua.temple01.com/qianshi.php?t=fs60 (籤卦結緣讚)
- **ตรวจทาน:** ทั้งสองแหล่งตรงกันทุกตัวอักษรครบ ๖๐ ใบ คู่ก้านกิ่ง (`label_orig`) ครบ ๖๐ คู่ไม่ซ้ำ
- **`grade_orig` = null:** ตำรานี้ไม่มีเกรดกำกับ ระดับ (`level`) จึงประเมินจากความหมายของกลอน
  - ดีมาก ๑๕ ใบ
  - ดี ๑๙ ใบ
  - ปานกลาง ๑๔ ใบ
  - ควรระวัง ๑๒ ใบ

**ข้อสังเกต:** ทั้งสองเว็บน่าจะมาจากผู้ดูแลกลุ่มเดียวกัน (ข้อมูลตรงกันทุกตัวอักษร) จึงยังไม่ใช่การยืนยันจากสองแหล่งที่เป็นอิสระต่อกัน ถ้ามีฉบับพิมพ์จริงจากวัดหรือศาลเจ้า ควรเทียบอีกรอบ
