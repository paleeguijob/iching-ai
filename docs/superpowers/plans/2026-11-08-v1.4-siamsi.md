# v1.4 เซียมซี Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ผู้ใช้เลือกตำราเซียมซี ดูโฆษณาแล้วเขย่ากระบอก เสี่ยงไม้ปัวยืนยัน แล้วอ่านใบเซียมซีจากตำราดั้งเดิมได้แม้ออฟไลน์ ถ้าอยากได้คำแปลตามคำถาม ก็ให้นักพรต (AI) "แปลความหมาย" โดยใช้สิทธิ์คำทำนายเดิม

**Architecture:** กฎทั้งหมด (สุ่มไม้, ไม้ปัว, โควตาเซียมซี, map เกรด) เป็น pure function ใน `core/domain` · ใบเซียมซีเป็นไฟล์ JSON ต่อชุด bundle ในแอป (`core/data`) และ copy ไป backend ด้วย `copy-data.mjs` เหมือน `hexagrams.json` · โควตาเซียมซีนับฝั่งแอปใน DataStore ไม่ยุ่งกับโควตาอี้จิงบน server · server เพิ่ม `POST /siamsi/interpret` ที่ใช้ `interpret()` เดิม (ตัดสิทธิ์/refund/stream) โดยเปลี่ยนแค่ prompt · Journal ใช้ `Reading` เดิม เพิ่มฟิลด์ `siamsi`

**Tech Stack:** Kotlin Multiplatform + Compose, Koin, Room, DataStore, Ktor · TypeScript + node:test (Cloud Functions), Firestore, Firebase Hosting

**Spec:** `docs/superpowers/specs/2026-11-08-siamsi-design.md` (r4)

## Global Constraints

- ทุกอย่างซ่อนอยู่จนกว่า `config/runtime.siamsiEnabled = true` · ค่าเริ่มต้น `false`
- ค่าเริ่มต้น config: `siamsiSets = [{id:"guanyin100",version:1},{id:"jiazi60",version:1}]`, `siamsiAdDrawsPerDay = 1`, `siamsiPremiumPerDay = 10`
- โควตาเซียมซี: ผู้ใช้ฟรี 1 ครั้ง/วัน (ดูโฆษณา 1 ครั้ง = 1 ใบ) · Premium 10 ครั้ง/วันไม่มีโฆษณา · **รวมทุกชุด** · วันนับตาม UTC+7 · ไม่ใช้เหรียญ · ไม่แตะ `adRewardsPerDay`/`adEarned`/`adUsed` ของอี้จิง
- ไม้ปัวเป็นขั้นบังคับ ไม่มีปุ่มข้าม ไม่มีตัวเลือกในตั้งค่า · ศักดิ์ 50% / หัวเราะ 25% / ไม่ 25% · รอบที่ 3 ยืนยันอัตโนมัติ · เขย่าใหม่เพราะปัวไม่ผ่านไม่นับโควตาและไม่ดูโฆษณาซ้ำ
- เลขไม้สุ่มด้วย `kotlin.random.Random` ที่ inject ได้ (production = `SecureRandom`-backed) **ก่อน** แอนิเมชัน uniform 1..`count`
- คำบนปุ่ม AI คือ "แปลความหมาย" · หัวการ์ดผลคือ "คำแปลจากนักพรต" · ห้ามใช้คำว่า "ขยายความ" ที่ใดเลย
- ข้อความ UI ภาษาไทยใช้ตามตาราง 2.2 ในสเปกตรงตัว รวมเลขไทย (๑, ๑๐)
- ข้อความท้ายใบ: "ไม่ได้รับการรับรองจากวัดหรือศาลเจ้าใด" และ "เซียมซีเพื่อการไตร่ตรองและความบันเทิง โปรดใช้วิจารณญาณ"
- ห้ามคัดลอกคำแปล/คำอธิบายไทยจากหนังสือหรือเว็บ — ใช้ได้เฉพาะกลอนต้นฉบับโบราณ ส่วน `poem_th`, `story`, `summary`, `topics` เขียนเอง
- UI ใช้ Quiet Ink: `ZenCard`, `ZenChip`, ปุ่มเดิม, `ZenSpacing`, กติกาชาดหนึ่งจุดต่อหน้า ห้าม hardcode สีใหม่
- คำสั่งเทสต์: backend `cd backend/functions && npm test` · แอป `cd frontend && ./gradlew :core:domain:allTests :core:data:testAndroidHostTest :composeApp:testAndroidHostTest`

@Test fun drawStickCoversEveryNumberAndIsUniform() {
    for (count in listOf(28, 60, 100)) {
        val r = Random(42); val hits = IntArray(count + 1)
        repeat(count * 2000) { hits[drawStick(count, r)]++ }
        assertEquals(0, hits[0]); assertTrue((1..count).all { hits[it] > 0 })
        val expected = 2000.0
        val chi = (1..count).sumOf { (hits[it] - expected).pow(2) / expected }
        assertTrue(chi < count * 1.5, "chi-square $chi too high for $count")
    }

}
