# v2.1 Deep Reading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ผู้ใช้ขอคำทำนายเชิงลึกของ reading ที่มีคำทำนาย AI อยู่แล้วได้ โดยใช้สิทธิ์ Premium ของเดือนหรือใช้ 3 เหรียญ และอ่านซ้ำได้จาก Journal

**Architecture:** กฎการตัดสิทธิ์อยู่ใน `core/quota.ts` เป็น pure function เหมือน `chargeReading` · endpoint ใหม่ `POST /readings/{id}/deep` ใน `core/api.ts` ใช้ lock ใน reading กันการขอซ้อน · กว้าซ่อนคำนวณใน `core/hexagrams.ts` · ฝั่งแอปเพิ่ม `OracleApi.deepReading` สถานะการ์ดเป็น pure function และเก็บข้อความลง Room

**Tech Stack:** TypeScript + node:test (Cloud Functions), Firestore, Kotlin Multiplatform + Compose, Room, Ktor

**Spec:** `docs/superpowers/specs/2026-11-07-v2-design.md` หัวข้อ 2

## Global Constraints

- ทุกอย่างในแผนนี้ต้องปิดอยู่จนกว่า `config/runtime.deepReadingEnabled = true` · ค่าเริ่มต้น `false`
- `aiEnabled = false` → endpoint ตอบ `503 ai_disabled` และแอปซ่อนการ์ด โดยไม่ตัดอะไร
- `deepModel` ต้อง pin เวอร์ชัน ห้ามใช้ `-latest` · `forceModel` ไม่มีผลกับ `deepModel`
- ค่าเริ่มต้น: `deepReadingCoinCost = 3`, `premiumDeepPerMonth = 2`, เดือนนับตาม UTC+7 (เหมือน `bangkokDay`)
- ลำดับการใช้สิทธิ์: สิทธิ์ Premium ของเดือน → เหรียญ
- `maxOutputTokens` ของคำทำนายเชิงลึก = 2500 (คำทำนายปกติยัง 2048)
- ราคาเหรียญในการ์ดมาจาก store เสมอ ห้าม hardcode
- ข้อความ UI ภาษาไทยใช้ตามตารางในสเปกหัวข้อ 2.1.1 ตรงตัว รวมเลขไทย (๓)
- คำสั่งเทสต์: backend `cd backend/functions && npm test` · emulator `npm run test:emulator` · แอป `cd frontend && ./gradlew :core:domain:jvmTest :core:data:testAndroid :composeApp:testAndroid`

## Review Focus

1. **เน็ตหลุดระหว่าง stream** → ผู้ใช้ต้องไม่เสียเหรียญฟรี ๆ และต้องไม่ได้ของฟรี: server สร้างต่อจนจบโดยไม่ abort แล้วบันทึกและตัดสิทธิ์ตามปกติ แอปดึงข้อความมาจาก `/readings` ทีหลัง (เทสต์ใน Task 5)
2. **กดซ้ำสองครั้งเร็ว ๆ / สองเครื่องพร้อมกัน** → ตัดสิทธิ์ครั้งเดียว อีก request ได้ `409 in_progress` (Task 4, Task 5)
3. **lock ค้างเพราะ function ตายกลางทาง** → หลัง 120 วินาทีขอใหม่ได้ (Task 4)
4. **ข้ามเดือนตอน 00:00 UTC+7 ของวันที่ 1** → สิทธิ์ Premium เริ่มใหม่ แต่ใช้ได้ไม่เกินเดือนละ 2 (Task 2)
5. **reading ที่เป็นตัวบทล้วน หรือ reading ของ uid อื่น** → `409 no_base_reading` / `404` ไม่ตัดอะไร (Task 5)

describe("deep reading charge", () => {
  const cfg = { ...DEFAULT_CONFIG, deepReadingEnabled: true };
  const now = Date.UTC(2026, 10, 30, 16, 59, 0); // 23:59 30 Nov in Bangkok
  const premium = (used: number, coins = 0) =>
    ({ ...normalizeUser({ premiumUntil: now + 86_400_000, coins }, bangkokDay(now)), deep: { month: "2026-11", used } });

  it("uses the Premium monthly allowance before coins", () => {
    const d = chargeDeep(premium(0, 5), cfg, now);
    assert.ok(d.ok && d.charge === "premium" && d.user.deep.used === 1 && d.user.coins === 5);
  });
  it("charges 3 coins once the allowance is used", () => {
    const d = chargeDeep(premium(2, 5), cfg, now);
    assert.ok(d.ok && d.charge === "coins" && d.user.coins === 2);
  });
  it("refuses with insufficient_coins and changes nothing", () => {
    assert.deepEqual(chargeDeep(premium(2, 2), cfg, now), { ok: false, reason: "insufficient_coins" });
  });
  it("starts the allowance again at Bangkok midnight on the 1st", () => {
    const next = now + 60_000; // 00:00 1 Dec in Bangkok
    const user = normalizeUser({ ...premium(2), premiumUntil: next + 86_400_000 }, bangkokDay(next));
    assert.equal(bangkokMonth(next), "2026-12");

  });

    assert.equal(chargeDeep(premium(0), DEFAULT_CONFIG, now).ok, false);
    assert.equal(chargeDeep(premium(0), { ...cfg, aiEnabled: false }, now).ok, false);
  });
  it("shares the rate limit with readings", () => {
    const d = chargeDeep({ ...premium(0), lastReadingAt: now - 2000 }, cfg, now);
    assert.ok(!d.ok && d.reason === "rate_limited");
  });
  it("refund gives back exactly what was taken", () => {
    const d = chargeDeep(premium(2, 5), cfg, now);
    assert.ok(d.ok);
    const back = refundDeep(d.user, d.charge, cfg);
    assert.equal(back.coins, 5);
    assert.equal(back.lastReadingAt, null);
  });
  it("status reports the allowance; free users get 0", () => {
    const s = status(premium(1), null, cfg, now);
    assert.deepEqual([s.deepEnabled, s.deepLeftThisMonth, s.deepCoinCost], [true, 1, 3]);

});

### Task 5: Endpoint `POST /readings/{id}/deep`

**Files:**

**Interfaces:**
- Consumes: `chargeDeep`, `refundDeep` (Task 2), `buildDeepPrompt` (Task 3), `reserveDeep`, `releaseDeep` (Task 4)
- Produces:
  - Route `POST /readings/{id}/deep` (regex id เดียวกับ `/outcome`) ตอบ SSE: `delta {text}` …, `done { model, status }` หรือ `error { code, refunded: true }`
  - HTTP error ก่อนเปิด stream: `404 reading_not_found`, `409 no_base_reading`, `409 in_progress`, `402 insufficient_coins`, `429 rate_limited` (`retryAfterSeconds`), `503 ai_disabled`
  - `toClientReading` เพิ่ม `deep: { text, createdAt } | null`
  - `GET /status` มี `deepEnabled`, `deepLeftThisMonth`, `deepCoinCost` (มาจาก `status()` ใน Task 2)

ลำดับใน handler: `cfg` ปิด → `503` · `getReading` ไม่พบ → `404` · `aiText` ว่าง → `409 no_base_reading` · มี `deep` → stream ข้อความเดิมเป็น `delta` เดียวแล้ว `done` (ไม่ตัด) · `reserveDeep` = `busy` → `409 in_progress` · `quotaTx(chargeDeep)` ไม่ผ่าน → `releaseDeep` แล้ว throw ตาม reason · เรียกโมเดล **โดยไม่ abort เมื่อ client ปิด connection** · สำเร็จ → `updateReading({ deep, deepPendingAt: null })` + log `deep_reading_cost` · ล้มเหลว → `refundDeep` + `releaseDeep` + `error`
