# อี้จิง AI 2.0 — ภาษาอังกฤษ + Widget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ปล่อย 2.0.0 (200) ที่มีเซียมซี (งาน v1.4 เดิม) + ภาษาอังกฤษครบทุกหน้าจอ เนื้อหา และคำทำนาย AI + เลือกภาษาในแอป + Widget กว้าประจำวันบน Android

**Architecture:** ข้อความ UI ย้ายไปไว้ใน interface `Strings` (แบ่งตาม feature) มี `ThStrings`/`EnStrings` ส่งผ่าน `LocalStrings` · เนื้อหาอังกฤษเป็นไฟล์ overlay `*.en.json` ที่ repository รวมกับไฟล์ไทยตามภาษา · server รับ `X-App-Lang` เก็บ `lang` ใน reading และเลือก prompt/safety/push ตามภาษา · Widget ใช้ Glance อ่านข้อมูลในเครื่อง

**Tech Stack:** Kotlin Multiplatform + Compose Multiplatform, Koin, DataStore, Ktor, Room · Jetpack Glance + WorkManager (ใหม่) · Firebase Functions (TypeScript, `node --test`), Firestore, FCM, Hosting

**Spec:** [`docs/superpowers/specs/2026-11-20-v2.0-english-widget-design.md`](../specs/2026-11-20-v2.0-english-widget-design.md)

## Global Constraints

- **ภาษาไทยต้องเหมือนเดิมทุกจุด:** `ThStrings` คือข้อความเดิมตรงตัว (copy จากโค้ด ไม่แก้คำ ไม่แก้ตัวเลขไทย) · เทสต์เดิมที่อ้างข้อความไทยต้องผ่านโดยไม่แก้ค่าที่คาด
- ภาษา: `AppLanguage { TH("th"), EN("en") }` · wire value `"th"` / `"en"` · ค่าอื่นหรือไม่มี → `TH`
- โหมดอังกฤษห้ามมีอักษรไทย (U+0E00–U+0E7F) ในข้อความที่ผู้ใช้เห็น ยกเว้น marker ภายใน `[สรุป]`, `[ดวงเด่น]`, `[ควรระวัง]`, `[คำแนะนำ]` ที่ถูกตัดออกก่อนแสดง
- คำแปลทำเองจากต้นฉบับจีน (public domain) + ฉบับไทยของทีม ห้ามคัดลอกคำแปลที่มีลิขสิทธิ์ (Wilhelm/Baynes, Legge ฉบับปรับปรุง ฯลฯ) และไม่ใช้ชุดชื่อกว้าของ Wilhelm ทั้งชุด
- ชื่อกว้าโหมดอังกฤษ: `"{nameCn} {pinyin} · {nameEn}"` เช่น "乾 Qián · Heaven"
- ข้อความอังกฤษ: ประโยคสั้น เรียบ สุภาพ ไม่ใช้ศัพท์ศาสนาเฉพาะไทย persona นักพรตไม่ใช้ "อาตมา" เรียกผู้ใช้ว่า "seeker" ได้
- ขีดความยาว (ตัวอักษร): `dailyMessageEn` ≤ 120 · `yearMessage` overview ≤ 200, work/love/money ≤ 80, blessing ≤ 60 · สรุป AI อังกฤษ ≤ 140
- runtime config ใหม่: `englishEnabled` (ค่าเริ่มต้น `true`), `hexagramsEnVersion` (ค่าเริ่มต้น `1`), `siamsiSets[].enVersion` (ค่าเริ่มต้น `1`)
- header `X-App-Lang` · push topic `daily-hexagram-th` (เดิม) และ `daily-hexagram-en`
- `versionCode = 200`, `versionName = "2.0.0"`
- ทุก feature ใหม่ปิดได้จาก `config/runtime` โดยไม่ต้องออกแอปใหม่
- คำสั่งตรวจ: `cd frontend && ./gradlew allTests :androidApp:testDebugUnitTest` · `cd backend/functions && npm test`

## Review Focus

1. **เปลี่ยนภาษาขณะมีหน้าจออื่นค้างอยู่ใน back stack** → ทุกหน้าที่เห็นหลังเปลี่ยนต้องเป็นภาษาใหม่ (วิธีของแผนนี้: สร้าง navigation ใหม่ด้วย `key(language)` แล้วกลับหน้าแรก) — เทสต์ใน Task 4 และตรวจใน Task 17 Step 6
2. **ถามต่อใน reading ไทยเก่าขณะแอปเป็นอังกฤษ** → server ตอบไทยตามภาษาของ reading ส่วน UI รอบ ๆ เป็นอังกฤษ — เทสต์ใน Task 9
3. **`englishEnabled = false` ขณะผู้ใช้เลือกอังกฤษไว้** → แอปแสดงไทย, subscribe topic ไทย, server ถือ request เป็นไทย, ค่าที่เลือกไว้ไม่หาย — เทสต์ใน Task 1, 9, 12
4. **ชุดเซียมซีที่ไม่มีไฟล์อังกฤษ** (เช่นชุดใหม่ที่ดาวน์โหลดภายหลัง) → ในโหมดอังกฤษไม่แสดงชุดนั้น แทนที่จะแสดงข้อความไทย — เทสต์ใน Task 7
5. **ข้อความอังกฤษยาวกว่าไทย** → ป้ายแท็บล่าง ปุ่ม และ widget 2×2 ไม่ถูกตัดบนจอกว้าง 360dp — ตรวจใน Task 17 (ภาพหน้าจอ) และกำหนด `maxLines`/`overflow` ใน Task 3–5
