# อี้จิง AI v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เพิ่มกวาประจำวัน, push 07:00, การ์ดแชร์, streak กับธีม และเสียงอ่าน โดยไม่เพิ่มการเรียก Gemini

**Architecture:** กติกาล้วนอยู่ใน `core/domain` (Kotlin) และ `backend/functions/src/core` (TypeScript) สถานะเก็บใน `AppSettings`/DataStore เท่านั้น FCM ผ่าน `NativeBridges` ส่วน TTS และแชร์ใช้ `expect/actual` แบบ `SoundPlayer`

**Tech Stack:** Kotlin Compose Multiplatform, Koin, DataStore, Firebase (FCM, Cloud Functions v2 scheduler), TypeScript + node:test

**Spec:** [docs/superpowers/specs/2026-11-01-v1.1-retention-design.md](../specs/2026-11-01-v1.1-retention-design.md)

## Global Constraints

- ทำงานบน branch `release/v1.1` · **ไม่ commit หรือ push จนกว่าเจ้าของแอปจะสั่ง**
- ฟีเจอร์ใหม่ทุกตัวห้ามเรียก Gemini และยกเว้น `dailyPush` ห้ามเพิ่ม endpoint หรือการเขียน Firestore
- วันทุกแบบนับที่ UTC+7 คงที่ ไม่ใช้เขตเวลาของเครื่อง
- สูตรกวา: `index = (epochDay * 37 + 11) mod 64` (ผลลบบวก 64), `id = index + 1`
- `dailyMessage` ไม่ว่างและไม่เกิน 120 ตัวอักษร
- ธีม: กระดาษหมึก 0 วัน, ไผ่เขียว 7, อรุณชาด 30, ราตรีหมึก 100
- ข้อความ UI เป็นภาษาไทยโทนเดียวกับแอป · การ์ดและข้อความแชร์ห้ามมีคำถามของผู้ใช้
- FCM topic `daily-hexagram-th`, channel `daily`, TTL 12 ชั่วโมง
