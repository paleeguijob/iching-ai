# v1.2 CNY Campaign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** แคมเปญตรุษจีนปีมะแม ๒๕๗๐: ผู้ใช้เสี่ยงทายกว้าประจำปีได้ฟรีปีละครั้ง เห็นข้อความที่เขียนไว้ล่วงหน้า ได้ธีมชาดทอง แชร์การ์ดแดงทอง และถามนักพรตเรื่องปีนี้ได้ด้วยสิทธิ์ปกติ

**Architecture:** server เป็นเจ้าของสถานะแคมเปญ (`config/runtime.campaign` → `GET /status`) และผลกว้าประจำปี (`users/{uid}/meta/year-{year}`) · กฎล้วนอยู่ใน `core/campaign.ts` ทดสอบได้โดยไม่มี Firebase · แอปเพิ่มหน้า `YearHexagramScreen` และใช้หน้าคำทำนายเดิมในโหมดปีใหม่

**Tech Stack:** TypeScript + node:test, Firestore, FCM, Cloud Scheduler · Kotlin Multiplatform + Compose, Ktor, DataStore

**Spec:** `docs/superpowers/specs/2026-11-07-v1.2-cny-campaign-design.md`

## Global Constraints

- ขึ้น Play production ภายใน 15 ม.ค. 2027 · `versionCode` 120 · `versionName` 1.2.0
- `campaign.enabled` ค่าเริ่มต้น `false` · config ไม่มีหรือผิดรูปแบบ = ปิด
- ช่วงเริ่มต้น: `startsAt` 2027-01-20T00:00+07:00, `endsAt` 2027-02-22T00:00+07:00, pushes 2027-02-05T19:00+07:00 และ 2027-02-06T08:00+07:00
- แอปไม่ใช้เวลาเครื่องตัดสินว่าแคมเปญเปิดอยู่ ใช้ `status.campaign.active` เท่านั้น
- กว้าประจำปีไม่เรียก AI ไม่ตัดโควตา · "ถามนักพรตเรื่องปีนี้" ตัดสิทธิ์ตามลำดับเดิมทุกอย่าง
- `yearMessage`: `overview` ≤ 200, `work`/`love`/`money` ≤ 80, `blessing` ≤ 60 ตัวอักษร · ไม่เอ่ยปีหรือนักษัตร · ไม่แนะนำการลงทุน กู้ยืม การรักษา หรือรับรองผล
- ข้อความ UI และ push ใช้ตามสเปกตรงตัว รวมเลขไทย
- การ์ดแชร์ปีใหม่ 1080×1920 ไม่มีคำถาม ไม่มีป้าย AI · การ์ดจากคำทำนาย AI ยังมีป้าย AI
- ธีมใหม่ต้องผ่าน contrast ข้อความหลัก ≥ 4.5:1
- คำสั่งเทสต์: backend `cd backend/functions && npm test` · emulator `npm run test:emulator` · แอป `cd frontend && ./gradlew :core:domain:jvmTest :core:data:testAndroid :composeApp:testAndroid`

```ts
describe("campaign", () => {
  const raw = { id: "cny-2027", year: 2027, startsAt: "2027-01-20T00:00:00+07:00", endsAt: "2027-02-22T00:00:00+07:00",
    pushes: ["2027-02-05T19:00:00+07:00"], enabled: true, yearContext: "x" };
  it("is active only while enabled and inside the window", () => {
    const c = parseCampaign(raw)!;
    assert.equal(campaignActive(c, Date.parse("2027-01-19T23:59:59+07:00")), false);
    assert.equal(campaignActive(c, Date.parse("2027-01-20T00:00:00+07:00")), true);
    assert.equal(campaignActive(c, Date.parse("2027-02-22T00:00:00+07:00")), false);
    assert.equal(campaignActive({ ...c, enabled: false }, c.startsAt), false);
  });
  it("treats a malformed config as no campaign", () => {
    for (const bad of [null, {}, { ...raw, startsAt: "soon" }, { ...raw, endsAt: raw.startsAt }, { ...raw, id: "" }, { ...raw, pushes: "x" }])
      assert.equal(parseCampaign(bad), null);
    assert.equal(mergeConfig({ campaign: { ...raw, year: "2027" } }).campaign, null);
  });
  it("is off by default and reported in status", () => {
    assert.equal(DEFAULT_CONFIG.campaign!.enabled, false);
    const cfg = mergeConfig({ campaign: raw });
    const s = status(normalizeUser(undefined, "2027-02-01"), null, cfg, Date.parse("2027-02-01T12:00:00+07:00"));
    assert.deepEqual(s.campaign, { id: "cny-2027", year: 2027, active: true, endsAt: Date.parse(raw.endsAt) });
  });
});
```
