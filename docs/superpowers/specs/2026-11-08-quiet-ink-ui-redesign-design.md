# v1.3 — Quiet Ink UI Redesign

วันที่: 2026-11-08 · Branch: `release/v1.3` · Mockups: `.superpowers/brainstorm/23458-1794129859/content/`
(`home-directions.html`, `quiet-ink-system.html`, `quiet-ink-lists.html`)

## เป้าหมาย

ขัดเกลา UI ทั้งแอปให้ดูพรีเมียมและอ่านง่ายขึ้น **โดยคงเอกลักษณ์ Zen หมึกบนกระดาษเดิม** (กระดาษ หมึก ไผ่ ชาด, 5 ธีม)
ทิศทางที่เลือก: **Quiet Ink** — ให้ตัวอักษร ระยะห่าง และพื้นผิวการ์ดทำงานแทนของตกแต่ง

### สิ่งที่ผู้ใช้บอก
- อยาก "สวยขึ้น" แบบขัดเกลาของเดิม ไม่เปลี่ยนแนว
- ทุกหน้าจอมีจุดที่ยังไม่สวย: หน้าแรก, คำทำนาย, ฉากโยนเหรียญ, คัมภีร์/บันทึก/ตั้งค่า
- เลือก Quiet Ink (A) สำหรับภาพรวม และ "แผ่นกระดาษเรียบ" (B) สำหรับคำทำนาย

### สมมติฐาน (แก้ได้)
- ไม่เปลี่ยน flow, navigation, ViewModel หรือ business logic — เป็นงานชั้น UI เท่านั้น
- ไม่มีการเปลี่ยน backend ใน v1.3
- การ์ดแชร์ (`feature/share`) คงหน้าตาเดิม (ยังใช้ม้วนคัมภีร์/`InkPaperPalette` ได้)

### เกณฑ์ความสำเร็จ
- ทุกหน้าจอใช้ token/คอมโพเนนต์ชุดเดียวกัน ไม่มีสี/มุมโค้ง/ขนาดตัวอักษรแบบ hard-code ใหม่
- ปุ่มหลักหน้าแรกไม่ชน/ถูกบังโดยแถบเมนูล่างอีก
- ตัวอักษรหลักผ่าน contrast ≥ 4.5:1 ทั้ง 5 ธีม รวมถึงบนพื้นการ์ดใหม่
- ภาพหน้าจอ store ชุดใหม่ (5 รูป) ดูเป็นชุดเดียวกัน

## 1 · ระบบพื้นฐาน (Design system)

### สี / พื้นผิว
- เพิ่มฟิลด์ใน `ZenPalette`: `card` (พื้นการ์ด) และ `cardShadow` (สีเงา)
  - กระดาษหมึก `#FFFFFF` · ไผ่ `#FBFDF7` · ชาดรุ่งอรุณ `#FFFBF7` · หมึกราตรี `#222833` · ชาดทอง `#5E1813`
  - เงา: ธีมสว่างใช้ `inkBlack` alpha 0.07, ธีมมืดใช้ดำ alpha 0.35
- เพิ่ม `ZenColors.Card` / `ZenColors.CardShadow` และ map `surfaceContainerLowest = card` ใน `ZenTheme`
- ค่าสีเดิมทั้งหมดไม่เปลี่ยน (`defaultThemeKeepsCurrentColors` ต้องผ่านต่อ)
- กติกา **ชาดหนึ่งจุดต่อหน้า**: `CinnabarRed` ใช้เป็นจุดเน้นเท่านั้น (จุดในปุ่มหลัก, วงเส้นแปร, เส้นขอบบนการ์ดคำทำนาย, จุดแท็บที่เลือก)

### ตัวอักษร (ปรับ `zenTypography()`)
- Charm (display) ใช้เฉพาะหัวข้อใหญ่ของหน้า ไม่เกิน 1 จุด/หน้า
- `bodyLarge`/`bodyMedium` lineHeight ≈ 1.8× ขนาดฟอนต์ (17/31 คงเดิม, 15/27)
- `labelSmall` ใช้เป็น "ป้ายกำกับ": letterSpacing 0.8sp, สี `BambooDeep`
- ตัด `SectionLabel` แบบเส้นสองข้างออก แทนด้วยป้ายกำกับธรรมดา (ชื่อ composable เดิม เปลี่ยนเฉพาะหน้าตา)

### รูปทรง / ระยะห่าง
- `Shapes`: small 8 → คงเดิม, medium 14 → 12, large 22 → 16
- ระยะห่างเป็นขั้น 4 · 8 · 12 · 20 · 28 — เพิ่ม `object ZenSpacing` ใน `ui/theme`
- ขอบข้างหน้าจอ 20dp (เดิม 24)

### คอมโพเนนต์ใหม่/ปรับ (`ui/components`)
| คอมโพเนนต์ | การเปลี่ยนแปลง |
|---|---|
| `ZenCard` (ใหม่) | พื้น `Card`, มุม 16, เงานุ่ม + เส้นล่าง 1dp `outlineVariant`; มี param `accentTop: Boolean` สำหรับเส้นชาด 3dp ด้านบน |
| `ZenPrimaryButton` | สูง 50, มุม 14 (เลิกทรงแคปซูล), จุดชาด 8dp หน้าข้อความ (param `showSeal = true`) |
| `ZenSecondaryButton` | มุม 12, เส้นขอบ `outline` |
| `ZenTextButton` (ใหม่) | ข้อความสี `InkSoft` สำหรับ action รอง เช่น "โยนต่อเนื่องจนครบ" |
| `ZenChip` (ใหม่) | ทรงแคปซูล; เลือกแล้ว = พื้นหมึก ตัวอักษรกระดาษ; ไม่เลือก = เส้นขอบ `outlineVariant` |
| `PaperBackground` | คงไล่สีกระดาษ; **ลดเอ็นโซและภูเขา** ให้จางลงครึ่งหนึ่ง และปิดภูเขาเป็นค่าเริ่มต้นบนหน้ารายการ |
| `HexagramFigure` | เส้นแปรใช้ **วงแหวนชาด** ล้อมเส้นแทนจุด/× ; เส้นที่ยังไม่โยนเป็นเส้นประจาง (`drawPlaceholder`) |
| `ZenTabBar` (`App.kt`) | จากแคปซูลลอย → แถบเต็มกว้าง พื้น `PaperMid` 92% + เส้นบน 1dp; แท็บที่เลือก = สีหมึก + จุดชาด 4dp ใต้ label |

## 2 · หน้าจอ

### หน้าแรก (`HomeScreen`)
ลำดับบนลงล่าง:
1. แถบบน: ตราซีล 易 เล็ก + "อี้จิง" · ไอคอนตั้งค่า
2. **การ์ดกวาประจำวัน** (ย้ายจากล่างสุดขึ้นมา) — `ZenCard` แนวนอน: รูปกวาเล็ก + ป้าย "กวาประจำวัน" + ชื่อ · แตะเปิด Daily
3. การ์ดแคมเปญ/ปีใหม่ (ถ้ามี) — `ZenCard` แบบเดียวกัน
4. หัวข้อ Charm "ถามทางแห่งเต๋า" + คำโปรยบรรทัดเดียว (ตัดอักษรจีน 問道 ขนาดใหญ่ออก)
5. ช่องคำถาม = `ZenCard` สูง ~96dp ไม่มีเส้นขอบ outline
6. แถวชิปหมวด (`ZenChip`)
7. บรรทัดโควตา (ข้อความเล็ก กึ่งกลาง) แทนการ์ดโฆษณาเต็มใบ: "วันนี้เหลือ ๒ คำถาม · ดูโฆษณาเพื่อรับเพิ่ม" — ข้อมูลจาก state เดิม
8. ปุ่มหลัก "เริ่มเสี่ยงทาย" **ตรึงเหนือแถบเมนูล่าง** (อยู่นอก scroll, เว้นระยะจาก tab bar 12dp)
- ตัวนับ streak ย้ายเป็นป้ายเล็กในแถบบน

### ฉากโยนเหรียญ (`DivinationScreen` / `TossStage`)
- แถบบน: ← "เสี่ยงทาย" + ตัวนับ "๔ / ๖" ชิดขวา; ใต้แถบเป็น progress bar 3dp
- คำถามเป็นตัวเอียงกึ่งกลาง (คงเดิม)
- รูปกวาเดิมขนาด แต่เส้นที่ยังไม่โยน = เส้นประจาง; เส้นแปร = วงชาด
- เหรียญ: เพิ่มเงาตกพื้น และเหลื่อมจังหวะตก (เหรียญกลางช้ากว่า ~80ms) — ปรับเฉพาะแอนิเมชันใน `TossStage`/`AncientCoin`
- ปุ่ม "โยนครั้งต่อไป" = `ZenPrimaryButton`; "โยนต่อเนื่องจนครบ" = `ZenTextButton`

### หน้าคำทำนาย (`ReadingContent`, `ReadingExtras`)
- คู่กวาหลัก → กวาแปร อยู่ใน `ZenCard` เดียว (ป้ายกำกับ, รูปกวา, อักษรจีน, เลข+ชื่อ, ความหมาย)
- **`OracleScroll` → แผ่นกระดาษเรียบ**: `ZenCard(accentTop = true)`; หัวการ์ด = ป้าย "คำชี้แนะจากนักพรต" สีชาด + ป้าย "AI" เล็กชิดขวา; เนื้อความ `bodyLarge` + Typewriter เดิม
- ลบ `ScrollRoller` ออกจากหน้าคำทำนาย (ยังเก็บไว้ถ้าการ์ดแชร์ใช้)
- **ไม่มี** หัวข้อสั้นที่ AI สร้าง ใน v1.3 (ต้องเปลี่ยน backend — แยกเป็นงานภายหลัง)
- ส่วนตัวบทคัมภีร์ (`ScriptureSection`/`ScriptureBlock`) และ extras (ฟังเสียง, แชร์, รายงาน) ใช้ `ZenCard` + ป้ายกำกับแบบใหม่
- disclaimer AI อยู่ท้ายสุด ตัวเล็กสี `InkFaint` (คงข้อความเดิม)

### คัมภีร์ (`LibraryScreens`)
- หัวข้อ Charm "คัมภีร์ ๖๔ กวา" + คำโปรยบรรทัดเดียว
- ช่องค้นหาเป็นพื้นการ์ด มุม 12 สูง ~44dp
- **ตัวกรองตรีกรม** (ใหม่): แถว `ZenChip` เลื่อนแนวนอน "ทั้งหมด" + 8 ตรีกรม; เลือกแล้วแสดงกวาที่มีตรีกรมนั้นเป็นบน *หรือ* ล่าง (ใช้ `Hexagram.upperTrigram`/`lowerTrigram`); ทำงานร่วมกับคำค้น
- รายการ: จาก grid 2 คอลัมน์ → `ZenCard` เดียวที่มีแถว: เลขไทยสีชาด · รูปกวาเล็ก · อักษรจีน+ชื่อ · ความหมาย; เส้นคั่น `outlineVariant`
- หน้ารายละเอียดกวาใช้การ์ดแบบหน้าคำทำนาย

### บันทึกชะตา (`JournalScreens`)
- เอาเส้นไทม์ไลน์และวงกลมออก
- จัดกลุ่มตามเดือน: ป้ายกำกับเดือน (สีไผ่) + `ZenCard` เดียวต่อเดือน มีแถวคั่นด้วยเส้น
- แถว: บรรทัดวันที่ย่อเลขไทย "๖ พ.ย. · 20:27" (+ " · ตัวบทคัมภีร์" ถ้าเป็นแบบไม่ใช้ AI) · คำถาม (titleSmall) · "震 เจิ้น → 豐 เฟิง" สีไผ่ · รูปกวาเล็กชิดขวา
- หน้ารายละเอียดบันทึกใช้ layout หน้าคำทำนาย

### ตั้งค่า (`SettingsScreen`)
- การ์ดบัญชีบนสุด: ซีล 易 · สถานะสมาชิก/เหรียญ · ปุ่มเล็ก "อัปเกรด" (ถ้ายังไม่ premium)
- รายการเดิมทั้งหมด จัดเป็นกลุ่ม (ป้ายกำกับกลุ่ม + `ZenCard` ที่มีแถวคั่นเส้น)
- ตัวเลือกธีม: แถวจุดสี 5 จุด จุดที่เลือกมีวงแหวนสีหมึก
- ไม่เพิ่ม/ลบการตั้งค่าใด ๆ

### หน้าอื่น — ใช้ระบบเดียวกัน ไม่จัด layout ใหม่
`OnboardingScreen`, `PaywallScreen`, `PreCastSheet`, `DailyScreen`, `YearHexagramScreen`, `AskYearScreen`:
เปลี่ยนเป็น `ZenCard`/ปุ่ม/ชิป/ตัวอักษรใหม่ ขอบข้าง 20dp และกติกาชาดหนึ่งจุด

## 3 · ขอบเขตที่ไม่ทำ
- ไม่เปลี่ยนการ์ดแชร์ ไอคอนแอป หรือฟอนต์
- ไม่เพิ่มธีมใหม่ ไม่เปลี่ยนค่าสีเดิม
- ไม่มีหัวข้อคำทำนายจาก AI

## 4 · การทดสอบ
- `ThemeContrastTest`: เพิ่มคู่ `inkBlack`/`card`, `inkSoft`/`card` ทุกธีม (≥ 4.5:1) และ `bambooDeep`/`card` (≥ 3:1 สำหรับป้ายกำกับ)
- Unit test ตัวกรองตรีกรม (ฟังก์ชัน pure ใน `LibraryViewModels`): ทั้งหมด / ตรีกรมบน / ตรีกรมล่าง / รวมกับคำค้น
- Test ที่มีอยู่ทั้งหมดต้องผ่าน (`./gradlew :composeApp:testAndroidHostTest :core:domain:allTests`)
- ตรวจด้วยตาบน emulator Android ทั้ง 5 ธีม: หน้าแรก, โยนเหรียญ, คำทำนาย, คัมภีร์, บันทึก, ตั้งค่า, paywall
- ถ่ายภาพหน้าจอ store ชุดใหม่แทน `docs/store/screenshots/01–05`

## 5 · ลำดับการทำ (สำหรับ implementation plan)
1. Tokens: `ZenPalette.card/cardShadow`, `ZenSpacing`, typography, shapes + contrast tests
2. Components: `ZenCard`, ปุ่ม, `ZenChip`, `ZenTextButton`, `SectionLabel`, `HexagramFigure`, `PaperBackground`, `ZenTabBar`
3. หน้าแรก → โยนเหรียญ → คำทำนาย
4. คัมภีร์ (+ ตัวกรองตรีกรม) → บันทึก → ตั้งค่า
5. หน้าอื่น ๆ
6. ตรวจทั้ง 5 ธีม, ภาพหน้าจอ store, bump เวอร์ชัน 1.3.0
