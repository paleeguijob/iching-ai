# อี้จิง AI v1.2 — แคมเปญตรุษจีน ปีมะแม ๒๕๗๐

7 พ.ย. 2026 · ต่อจาก [v1.1](2026-11-01-v1.1-retention-design.md) · ก่อน [v2](2026-11-07-v2-design.md)

## 1. เป้าหมาย

ใช้ตรุษจีน 2027 (เสาร์ 6 ก.พ. 2027 เริ่มปีมะแมธาตุไฟ 丁未) ซึ่งเป็นช่วงที่สายมูค้นหาเยอะที่สุดของปี เพื่อดึงผู้ใช้ใหม่และให้คนแชร์ต่อ พา MAU เข้าใกล้เกณฑ์ 5,000 ของ v2 ส่วนที่ฟรีไม่เรียก AI

| KPI (ช่วงแคมเปญ) | เป้า |
|---|---|
| ผู้ใช้ active ที่เสี่ยงทายกว้าประจำปี | ≥ 40% |
| อัตราแชร์การ์ดประจำปี | ≥ 15% ของการเสี่ยงทายกว้าประจำปี |
| ยอดติดตั้งต่อวัน | ≥ 2 เท่าของค่าเฉลี่ย 4 สัปดาห์ก่อนแคมเปญ |
| คำทำนาย AI จากปุ่ม "ถามนักพรตเรื่องปีนี้" | ≥ 10% ของการเสี่ยงทายกว้าประจำปี |
| ค่า API ÷ รายได้สุทธิ | < 50% (คงเดิม) |

**กำหนดเวลา:** ขึ้น Play production ภายใน **15 ม.ค. 2027** (เผื่อ review และแก้ปัญหาก่อนเปิดแคมเปญ 20 ม.ค.) · `versionCode` 120 เว้น 117–119 ไว้ให้ v1.1 ออก patch

**สมมติฐาน:** v1.1 ขึ้น store แล้ว · Android เท่านั้น iOS ตาม `RELEASE.md` หัวข้อ 9

## 2. ช่วงแคมเปญและสวิตช์

ตั้งใน `config/runtime.campaign` (ไม่มีหรือผิดรูปแบบ = ปิด) ตามแบบ kill-switch เดิม

| ฟิลด์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `campaign.id` | `"cny-2027"` | ใช้เป็น key ข้อมูลและ analytics |
| `campaign.year` | `2027` | ปีของกว้าประจำปี |
| `campaign.startsAt` | `2027-01-20T00:00+07:00` | แสดงการ์ดแคมเปญตั้งแต่เวลานี้ |
| `campaign.endsAt` | `2027-02-22T00:00+07:00` | ครอบคลุมหยวนเซียว (20 ก.พ.) |
| `campaign.pushes` | `["2027-02-05T19:00+07:00", "2027-02-06T08:00+07:00"]` | เวลาส่ง push แคมเปญ |
| `campaign.enabled` | `false` | เปิดเองเมื่อพร้อม ไม่ต้องออกเวอร์ชันใหม่ |

- แอปรู้สถานะแคมเปญจาก `GET /status` ที่เพิ่ม `campaign: { id, year, active, endsAt } | null` (`active` = `enabled` และเวลาปัจจุบันอยู่ในช่วง) ไม่อ่านเวลาเครื่อง
- **หลังจบแคมเปญ:** การ์ดบนหน้าแรกหาย, กว้าประจำปีที่ได้ไปแล้วยังเปิดดูได้ตลอดปีจากหน้า Journal และการ์ดในหน้าตั้งค่า "กว้าประจำปี ๒๕๗๐", ธีมที่ได้ยังอยู่ถาวร
- ปีหน้าใช้โค้ดเดิม เปลี่ยนแค่ config และข้อความบริบทปีในข้อ 5

## 3. เสี่ยงทายกว้าประจำปี (ฟรี ไม่เรียก AI)

### 3.1 หน้าจอ

**การ์ดแคมเปญบนหน้าแรก** อยู่เหนือการ์ดกว้าประจำวัน แสดงเฉพาะตอน `campaign.active`

| สถานะ | หัวข้อ | ข้อความรอง | ปุ่ม |
|---|---|---|---|
| ยังไม่เสี่ยงทาย | เสี่ยงทายกว้าประจำปีมะแม ๒๕๗๐ | ตั้งจิตรับปีใหม่ ฟ้าประทานหนึ่งกว้าให้ท่านทั้งปี | เสี่ยงทายรับปีใหม่ |
| เสี่ยงทายแล้ว | กว้าประจำปีของท่าน: {ชื่อกว้าสั้น} | {คำอวยพร} | ดูกว้าประจำปี |

**พิธีเสี่ยงทาย:** ใช้หน้าจอโยนเหรียญ 6 ครั้งเดิม (haptic + เสียงเดิม) เปลี่ยนแค่หัวข้อเป็น "ตั้งจิตอธิษฐานรับปีใหม่" และไม่มีช่องพิมพ์คำถาม

**หน้ากว้าประจำปี** `YearHexagramScreen`

1. หัว: "กว้าประจำปีมะแม ๒๕๗๐" + รูปกว้า + ชื่อกว้า
2. ภาพรวมปี (`yearMessage.overview`)
3. การงาน · ความรัก · การเงิน (`yearMessage.work`, `.love`, `.money`) เป็นสามบล็อกสั้น
4. คำอวยพร (`yearMessage.blessing`) ในกรอบตราประทับ
5. ปุ่มหลัก "แชร์การ์ดปีใหม่" · ปุ่มรอง "ถามนักพรตเรื่องปีนี้" (ข้อ 5)
6. ลิงก์ "อ่านตัวบทคัมภีร์ของกว้านี้" ไปหน้า Library เดิม
7. ข้อความเล็กท้ายหน้า: "ข้อความประจำปีเขียนไว้ล่วงหน้าจากความหมายของกว้า ใช้เพื่อการสะท้อนคิด"

- เสี่ยงทายได้ปีละครั้งต่อบัญชี เปิดใหม่ได้ผลเดิมเสมอ ไม่มีปุ่มเสี่ยงใหม่
- ไม่มีเน็ต → แสดง "ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อรับกว้าประจำปี" พร้อมปุ่มลองใหม่ เพราะผลต้องตรงกันทุกเครื่อง
- ครั้งแรกที่ได้กว้าประจำปี แสดงข้อความครั้งเดียว "ท่านได้รับธีมชาดทอง เลือกใช้ได้ในหน้าตั้งค่า"

### 3.2 เนื้อหา

เพิ่มฟิลด์ `yearMessage` ให้ทั้ง 64 กว้าใน `hexagrams.json` (และ `docs/content/part*.json`)

| ฟิลด์ | ความยาวสูงสุด | เนื้อหา |
|---|---|---|
| `overview` | 200 ตัวอักษร | ภาพรวมของปีตามความหมายกว้า |
| `work` | 80 | การงาน |
| `love` | 80 | ความรัก |
| `money` | 80 | การเงิน |
| `blessing` | 60 | คำอวยพรปีใหม่ ใช้บนการ์ดแชร์และการ์ดหน้าแรก |

- เขียนแบบไม่ผูกกับปี 2027 (ไม่เอ่ยปีหรือนักษัตร) เพื่อใช้ซ้ำปีหน้า
- แนวชวนสะท้อนคิดเหมือน `dailyMessage` · ห้ามแนะนำการลงทุน การกู้ยืม การรักษา หรือรับรองผลลัพธ์ เช่น "รวยแน่"
- Claude ร่างลง `docs/content/year-messages.md` · เจ้าของแอปตรวจก่อนปล่อย
- เทสต์ตรวจว่าทุกกว้ามีครบ 5 ฟิลด์และไม่เกินความยาว

### 3.3 Server

**Endpoint ใหม่**

- `GET /year-hexagram` → `{ year, primaryId, lines, coins, castAt } | 404`
- `POST /year-hexagram` → เสี่ยงทายด้วย `castHexagram` เดิมแล้วตอบรูปแบบเดียวกัน

| ลำดับ | การทำงาน |
|---|---|
| 1 | `campaign.active` เป็น false → `409 campaign_inactive` (ยกเว้นมีผลอยู่แล้ว ให้ส่งของเดิม) |
| 2 | ใน transaction: มี `users/{uid}/meta/year-{year}` แล้ว → ส่งของเดิม · ไม่มี → เสี่ยงทายและบันทึก |
| 3 | เพิ่มธีม `cinnabar_gold` ใน `users/{uid}/meta/streak.unlocked` (ใช้ `mergeStreaks` เดิม) |

- ไม่มีกว้าแปร (relating) ในกว้าประจำปี: เก็บ `lines` ไว้แสดงรูปกว้า แต่ข้อความใช้กว้าหลักเท่านั้น เพื่อให้อ่านง่ายและตรงกับข้อความที่เขียนไว้
- ไม่ตัดโควตา ไม่เรียก AI · ใช้ `minSecondsBetweenReadings` เดิมกันกดรัว
- `POST /account/merge` ย้าย `meta/year-*` ถ้าบัญชีปลายทางยังไม่มีปีนั้น · `DELETE /account` ลบด้วย

### 3.4 ธีมชาดทอง

- เพิ่ม `cinnabar_gold` ใน `THEMES` (`core/streak.ts`) และ palette ฝั่งแอป: พื้นแดงชาดเข้ม ตัวอักษรทองอ่อน
- เทสต์ contrast ข้อความหลักบนพื้นหลัง ≥ 4.5:1 เหมือนธีมอื่น
- ในหน้าตั้งค่า ธีมที่ยังล็อกแสดง "รับได้จากการเสี่ยงทายกว้าประจำปี" ระหว่างแคมเปญ และ "ธีมพิเศษตรุษจีน" หลังจบ

## 4. การ์ดแชร์ปีใหม่

ต่อยอด `feature/share` ของ v1.1 (`ShareCard`, `TrigramScene`)

- ขนาด 1080×1920 เหมือนเดิม · โทนแดงชาด-ทอง ลายเมฆมงคลขอบการ์ด
- เนื้อหา: "กว้าประจำปีมะแม ๒๕๗๐", รูปกว้า, ชื่อกว้า (จีน + ไทย), `blessing`, ตราประทับชาด, ชื่อแอปและลิงก์ Play Store
- ไม่แสดงคำถามหรือข้อมูลส่วนตัว · ไม่มีป้าย AI เพราะไม่ใช่เนื้อหาจาก AI
- การ์ดจากคำทำนาย AI ในข้อ 5 ใช้การ์ดคำทำนายเดิมของ v1.1 (มีป้าย AI) แต่เปลี่ยนเป็นโทนแดงทองระหว่างแคมเปญ

## 5. ถามนักพรตเรื่องปีนี้ (ใช้สิทธิ์ปกติ)

**หน้าจอ:** กดปุ่มรองในหน้ากว้าประจำปี → หน้าตั้งคำถามเดิม หัวข้อ "ถามนักพรตเรื่องปีนี้" หมวดถูกเลือกไว้เป็น "ปีใหม่" และตัวอย่างคำถาม "ปีนี้การงานของข้าพเจ้าควรมุ่งไปทางใด" · ไม่มีการโยนเหรียญ ไปหน้าคำทำนายทันทีโดยแสดงกว้าประจำปีเป็นผลเสี่ยงทาย

**การตัดสิทธิ์:** เหมือนคำทำนายปกติทุกอย่าง (Premium → โฆษณา → เหรียญ) รวมทั้ง pre-cast offer และข้อเสนอเมื่อสิทธิ์หมด ถามได้ไม่จำกัดครั้งตามสิทธิ์ที่มี

**Server:** `POST /divine` รับ `mode: "year"`

- โหลด `meta/year-{campaign.year}` ไม่มี → `409 no_year_hexagram`
- สร้าง reading ใหม่ด้วย `lines`/`coins` ของกว้าประจำปี (ไม่เสี่ยงทายใหม่) · `category = "newyear"` · ฟิลด์ใหม่ `yearOf: 2027`
- ผ่าน safety filter เดิม
- prompt: เพิ่มบรรทัดบริบท `[บริบทปี] ปีมะแมธาตุไฟ (丁未) เริ่ม 6 ก.พ. 2027 — กว้านี้คือกว้าประจำปีของผู้แสวงหา ให้ตีความเป็นแนวทางทั้งปี` · ข้อความนี้อยู่ใน config ไม่ hardcode
- `CATEGORIES` เพิ่ม `newyear` (`CATEGORY_TH`: "ปีใหม่") · แอปแสดงหมวดนี้เฉพาะหน้านี้ ไม่อยู่ในรายการหมวดปกติ
- ถามต่อ (Premium) ใช้ได้ตามเดิม
- reading บันทึกลง Journal ตามปกติ พร้อมป้าย "กว้าประจำปี"

## 6. Push แคมเปญ

- Cloud Function ใหม่ `campaignPush` ตั้งเวลา `0 * * * *` (ทุกชั่วโมง) เขต `Asia/Bangkok` · ส่งเมื่อเวลาปัจจุบันตรงชั่วโมงของรายการใน `campaign.pushes` และ `campaign.enabled`
- ส่งไป topic `daily-hexagram-th` เดิม (เฉพาะคนที่เปิดรับแจ้งเตือนอยู่แล้ว) TTL 6 ชั่วโมง
- กันส่งซ้ำ: เขียน `campaignPushes/{campaignId}-{index}` ใน transaction ก่อนส่ง มีแล้ว = ข้าม
- ข้อความ (data `{type: "campaign", campaignId}` แตะแล้วเปิดหน้ากว้าประจำปี หรือพิธีเสี่ยงทายถ้ายังไม่มี)

| ครั้ง | title | body |
|---|---|---|
| คืนก่อนตรุษจีน | คืนส่งท้ายปีมะเมีย | ตั้งจิตรับปีมะแม เสี่ยงทายกว้าประจำปีของท่านได้แล้ววันนี้ |
| เช้าตรุษจีน | ซินเจียยู่อี่ ซินนี้ฮวดไช้ | ฟ้าเปิดปีใหม่ รับกว้าประจำปีมะแม ๒๕๗๐ ของท่าน |

- ตรรกะเลือกข้อความและเวลาอยู่ใน `core/` ทดสอบได้โดยไม่ต้องมี Firebase
- Push 07:00 เดิมในวันเดียวกันยังส่งตามปกติ

## 9. การทดสอบ

**Server**
- สถานะแคมเปญ: ก่อน `startsAt`, ระหว่าง, หลัง `endsAt`, `enabled = false`, config ผิดรูปแบบ → ปิด
- `POST /year-hexagram`: ครั้งแรกได้ผลและธีม, ครั้งต่อไปได้ผลเดิม, สองเครื่องพร้อมกันได้ผลเดียวกัน, แคมเปญปิดแต่มีผลแล้วยังได้ของเดิม, ปิดและไม่มีผล → `409`
- `/divine mode: "year"`: ใช้กว้าประจำปีไม่เสี่ยงใหม่, ตัดสิทธิ์ปกติ, ไม่มีกว้าประจำปี → `409`, prompt มีบริบทปีและหมวดปีใหม่
- `campaignPush`: ส่งตรงชั่วโมง, ไม่ส่งซ้ำเมื่อ function รันซ้ำ, ไม่ส่งเมื่อปิด
- รวมบัญชีและลบบัญชี (emulator)
- เนื้อหา `yearMessage` ครบ 64 กว้าและไม่เกินความยาว

**แอป**
- การ์ดหน้าแรกตามตารางข้อ 3.1 และไม่แสดงเมื่อแคมเปญปิด
- ธีมชาดทอง: contrast ผ่าน, ปลดล็อกหลังได้กว้าประจำปี, คงอยู่หลังจบแคมเปญ
- การ์ดแชร์ 1080×1920 ไม่ถูกตัด ไม่มีคำถาม

**เครื่องจริง** (ตั้ง `startsAt` ใน emulator/dev ให้เป็นตอนนี้)
- เสี่ยงทาย → หน้ากว้าประจำปี → แชร์ไป LINE และ IG Story → ภาพครบ
- ลบแอป → ติดตั้งใหม่ด้วยบัญชี Google เดิม → ได้กว้าประจำปีเดิมและธีมยังอยู่
- ถามนักพรตเรื่องปีนี้ด้วยบัญชีฟรี → ดูโฆษณา → ได้คำทำนายของกว้าประจำปี → อยู่ใน Journal พร้อมป้าย
- ส่ง push ทดสอบ `type=campaign` → แอปปิดอยู่ แตะแล้วเปิดหน้าถูก
- ทุกหน้าใหม่บนจอแคบและทุกธีม
