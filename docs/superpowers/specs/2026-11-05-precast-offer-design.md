# อี้จิง AI — เสนอโฆษณาและแพ็กเกจก่อนเสี่ยงทาย

5 พ.ย. 2026 · ต่อยอดจาก [Product Spec หัวข้อ "แถบคำชี้แนะคงเหลือ" และ "ข้อเสนอเมื่อสิทธิ์หมด"](../../specs/2026-10-31-store-release-product-spec.md)

## 1. ปัญหาและเป้าหมาย

**ปัญหา:** ผู้ใช้ฟรีที่ใช้คำทำนายฟรีของวันแล้ว ต้องโยนเหรียญครบ ๖ ครั้ง เห็นตัวบทคัมภีร์ดิบก่อน แล้วปุ่มชมโฆษณาจึงโผล่ใต้กวา
หน้าแรกมีข้อความอธิบายไว้ ("กดเริ่มเสี่ยงทายได้เลย แล้วชมโฆษณาในหน้าคำทำนาย") แต่ลำดับยังกลับหัว: ผู้ใช้เห็นคำตอบแบบไม่เต็มก่อน แล้วค่อยถูกขอให้ทำบางอย่างเพื่อได้คำตอบเต็ม
กรณีไม่เหลือทางฟรีแล้ว ข้อเสนอ Premium หรือเหรียญก็ขึ้นหลังเสี่ยงทายเช่นกัน

**เป้าหมาย:** ตัดสินใจให้จบก่อนโยนเหรียญ — กด "เริ่มเสี่ยงทาย" แล้วเลือกว่าจะชมโฆษณา ซื้อ หรืออ่านตัวบทอย่างเดียว จากนั้นการเสี่ยงทายดำเนินไปรวดเดียวจนได้คำชี้แนะ

| ตัววัด | เป้า |
|---|---|
| สัดส่วนผู้ใช้ที่เห็น sheet แบบโฆษณาแล้วชมโฆษณาจนจบ | สูงกว่าอัตราชมโฆษณาจากการ์ดหลังเสี่ยงทายในปัจจุบัน |
| `quota_upsell_purchase` ต่อผู้ใช้ที่ไม่เหลือสิทธิ์ | ไม่ต่ำกว่าเดิม (ดูแยกตาม `placement`) |

**ไม่อยู่ในขอบเขต:**
- ไม่เปลี่ยน server: `POST /ad-reward` เพิ่มสิทธิ์จากโฆษณาอยู่แล้ว และ `chargeReading` ตัดสิทธิ์นั้นเองตอน `POST /divine`
- ไม่เปลี่ยนลำดับการตัดสิทธิ์ ราคา หรือโควตา
- ไม่แตะ Premium ที่ใช้สิทธิ์ของวันครบ (การ์ดเดิมของ Premium คงเดิม)

## 2. กฎการเปิด sheet

ฟังก์ชันล้วน `preCastOffer(status, online): PreCastOffer` ใน `feature/home/PreCastGate.kt` คืนค่า `NONE`, `AD` หรือ `UPSELL`
ตรวจตามลำดับ แถวแรกที่ตรงชนะ:

| # | สถานะตอนกด "เริ่มเสี่ยงทาย" | ผล |
|---|---|---|
| 1 | `online = false` (ยังไม่เคยได้คำตอบจาก server ในรอบนี้) | `NONE` — เสี่ยงทายเลย |
| 2 | `aiEnabled = false` | `NONE` |
| 3 | `premium = true` | `NONE` |
| 4 | `readingsLeft > 0` (รวมสิทธิ์ฟรี สิทธิ์จากโฆษณาที่ยังไม่ใช้ และเหรียญ) | `NONE` |
| 5 | `adsWatchableLeft > 0` | `AD` |
| 6 | อื่น ๆ | `UPSELL` |

**สถานะที่ใช้ตัดสิน:** ตอนกด เรียก `session.refreshStatus()` รอไม่เกิน 1,500 ms ถ้าเกินเวลาหรือไม่สำเร็จ ใช้ `session.status` ล่าสุด
ระหว่างรอ ปุ่ม "เริ่มเสี่ยงทาย" แสดงสถานะกำลังโหลดและกดซ้ำไม่ได้ เหตุที่รีเฟรชก่อน: สถานะอาจค้างจากเมื่อวานหรือจากเครื่องอื่น

**ทางสำรอง:** ถ้ากฎตัดสินผิดเพราะสถานะล้าสมัย (เช่น ออฟไลน์ตอนกด) การ์ดหลังเสี่ยงทายใน `ReadingNoticeCard` ยังทำงานเหมือนเดิมทุกอย่าง จึงไม่มีผู้ใช้คนไหนเสียทาง

## 3. Sheet

`ModalBottomSheet` ใน `feature/home/PreCastSheet.kt` ใช้สไตล์เดียวกับการ์ดในแอป (กระดาษ, ปุ่ม `ZenPrimaryButton` / `ZenSecondaryButton`)
หัวข้อทั้งสองแบบแสดงคำถามที่ผู้ใช้พิมพ์ (ตัดที่ ๒ บรรทัด) หรือ "อธิษฐานในใจ" ถ้าเว้นว่าง เพื่อย้ำว่ายังไม่เสียคำถาม

### 3.1 แบบโฆษณา (`AD`)

| ส่วน | ข้อความ |
|---|---|
| หัวข้อ | คำชี้แนะฟรีของวันนี้ใช้แล้ว |
| คำอธิบาย | ชมโฆษณาสั้น ๆ เพื่อรับคำชี้แนะจากนักพรตสำหรับการเสี่ยงทายครั้งนี้ |
| ปุ่มหลัก | ชมโฆษณาสั้น แล้วเริ่มเสี่ยงทาย (เหลือ {adsWatchableLeft เลขไทย}) |
| ปุ่มรอง | เสี่ยงทาย อ่านตัวบทคัมภีร์อย่างเดียว |
| ลิงก์เล็ก | Premium · วันละ ๑๐ คำทำนาย ไม่มีโฆษณา → เปิด paywall |

ระหว่างเปิดโฆษณา ปุ่มหลักเป็น "กำลังเปิดโฆษณา..." และกดปุ่มอื่นใน sheet ไม่ได้

### 3.2 แบบขาย (`UPSELL`)

ข้อความชุดเดียวกับการ์ด "ข้อเสนอเมื่อสิทธิ์หมด" ใน Product Spec เพื่อให้ผู้ใช้เห็นข้อเสนอเดียวกันไม่ว่าจะเจอที่ไหน

| ส่วน | ข้อความ |
|---|---|
| หัวข้อ | คำชี้แนะฟรีและจากโฆษณาของวันนี้ครบแล้ว |
| คำอธิบาย | ท่านยังรับคำชี้แนะจากนักพรตสำหรับการเสี่ยงทายครั้งนี้ได้ |
| ปุ่มหลัก | Premium · วันละ ๑๐ คำทำนาย · {trialTh ถ้า store บอกว่ายังมีสิทธิ์ทดลอง} → เปิด paywall |
| ปุ่มรอง | เหรียญอี้จิง ๑๐ เหรียญ · {ราคาจาก store} → ซื้อทันที ไม่ผ่าน paywall |
| ปุ่มที่สาม (TextButton) | เสี่ยงทาย อ่านตัวบทคัมภีร์อย่างเดียว |
| ข้อความเล็ก | หรือกลับมาใหม่พรุ่งนี้ สิทธิ์ฟรีเริ่มนับใหม่ทุกวัน |

- ราคาเหรียญและสิทธิ์ทดลองโหลดจาก `session.products()` ครั้งแรกที่ sheet แบบนี้เปิด ระหว่างโหลดหรือโหลดไม่ได้ ซ่อนราคาแต่ปุ่มยังกดได้ (ตามกฎใน Product Spec)
- ระหว่างซื้อ ปุ่มรองเป็น "กำลังดำเนินการ..." และกดปุ่มอื่นไม่ได้

### 3.3 พร้อมแล้ว (`READY`)

ถ้าระหว่างที่ sheet เปิดอยู่ `status.readingsLeft > 0` (เช่น ซื้อ Premium จาก paywall แล้วกลับมา) เนื้อหา sheet เปลี่ยนเป็น:

| ส่วน | ข้อความ |
|---|---|
| หัวข้อ | พร้อมรับคำชี้แนะแล้ว |
| ปุ่มหลัก | เริ่มเสี่ยงทาย |

ไม่พาไปหน้าเสี่ยงทายเอง เพราะผู้ใช้เพิ่งกลับจากหน้าจ่ายเงิน การให้กดอีกครั้งชัดเจนกว่าการเปลี่ยนหน้าเอง

## 4. Flow หลังเลือก

| การกระทำ | ผลลัพธ์ | ข้อความ (แถบล่างของ sheet) |
|---|---|---|
| ชมโฆษณา → `AdResult.Granted` | ปิด sheet แล้วไปหน้าเสี่ยงทายพร้อมคำถามและหมวดเดิม | — |
| ชมโฆษณา → `NotCompleted` | อยู่ที่ sheet | ต้องชมโฆษณาจนจบจึงจะได้รับสิทธิ์ |
| ชมโฆษณา → `Error` (ไม่มีโฆษณาพร้อม) | อยู่ที่ sheet | ยังไม่มีโฆษณาพร้อมแสดง โปรดลองใหม่อีกครู่ หรือเสี่ยงทายอ่านตัวบทไปก่อน |
| ชมโฆษณา → `LimitReached` | รีเฟรชสถานะ แล้ว sheet เปลี่ยนเป็นแบบขาย | วันนี้ใช้สิทธิ์ชมโฆษณาครบแล้ว |
| ซื้อเหรียญ → `Success` | ปิด sheet แล้วไปหน้าเสี่ยงทาย (เหรียญถูกตัด ๑ เหรียญตอนเริ่มทำนาย) | — |
| ซื้อเหรียญ → `Pending` / `AwaitingPayment` / `Error` | อยู่ที่ sheet | ข้อความเดิมจาก `PaywallViewModel` (`PENDING_MESSAGE`, `AWAITING_PAYMENT_MESSAGE`, "การชำระเงินไม่สำเร็จ โปรดลองใหม่อีกครั้ง") |
| ซื้อเหรียญ → `Cancelled` | อยู่ที่ sheet | — |
| กด Premium | เปิด paywall ทับ sheet ซึ่งยังเปิดค้างอยู่ | — |
| อ่านตัวบทอย่างเดียว | ปิด sheet แล้วไปหน้าเสี่ยงทายตามเดิม (server ตอบ `QUOTA` และการ์ดหลังเสี่ยงทายทำงานตามปกติ) | — |
| ปัดปิด / กด back | ปิด sheet อยู่หน้าแรก คำถามและหมวดยังอยู่ | — |

**สิทธิ์จากโฆษณาที่ได้แล้วแต่ไม่ได้ใช้:** เช่น ชมโฆษณาจบแล้วกด back ออกจากหน้าเสี่ยงทายก่อนโยน สิทธิ์ยังอยู่บน server จนถึงเที่ยงคืนเวลาไทย แถบหน้าแรกแสดงเป็น "วันนี้เหลือคำชี้แนะ ๑" และกดเริ่มครั้งถัดไปเสี่ยงทายได้เลยตามกฎแถว 4

**Rate limit:** ถ้าเริ่มทำนายภายใน 8 วินาทีหลังคำทำนายก่อน server ตอบ `RATE_LIMITED` การ์ดเดิม "โปรดเว้นจังหวะหายใจ" พร้อมปุ่มถามอีกครั้งรับต่อ สิทธิ์จากโฆษณายังไม่ถูกตัด

## 5. หน้าแรก

แถว "ผู้ใช้ทั่วไป สิทธิ์วันนี้ 0 ไม่มีเหรียญ และยังดูโฆษณาได้" ในตารางแถบคำชี้แนะ เปลี่ยนข้อความรอง:

| เดิม | ใหม่ |
|---|---|
| กดเริ่มเสี่ยงทายได้เลย แล้วชมโฆษณาในหน้าคำทำนาย | กดเริ่มเสี่ยงทาย แล้วชมโฆษณาสั้นก่อนโยนเหรียญ |

แถวอื่นในตารางคงเดิม แถบยังกดไม่ได้เหมือนเดิม

## 6. โครงสร้างโค้ด

| หน่วย | หน้าที่ | ขึ้นกับ |
|---|---|---|
| `PreCastGate.kt` (ใหม่) | `enum PreCastOffer { NONE, AD, UPSELL }` และฟังก์ชัน `preCastOffer(status, online)` ตามตารางหัวข้อ 2 | `AccountStatus` เท่านั้น |
| `HomeViewModel` (แก้) | `onStart(question, category)` รีเฟรชสถานะ ใช้กฎ แล้วส่ง event "ไปหน้าเสี่ยงทาย" หรือเปิด sheet · `onWatchAd()`, `onBuyCoins()`, `onScriptureOnly()`, `onPremium()`, `onSheetDismissed()` · `sheet: StateFlow<PreCastSheetUi?>` (แบบ, สินค้า, กำลังทำงาน, ข้อความ) | `AppSession` (`refreshStatus`, `status`, `online`, `watchAdForReading`, `products`, `purchase`, `log`) |
| `PreCastSheet.kt` (ใหม่) | วาด sheet จาก `PreCastSheetUi` (แบบ `AD`, `UPSELL` หรือ `READY`) ไม่มี logic · `READY` เป็นสถานะของ sheet ไม่ใช่ผลของ `preCastOffer` | — |
| `HomeScreen` (แก้) | ปุ่มเริ่มเรียก `onStart` · เก็บคำถามและหมวดใน `rememberSaveable` ตามเดิม · รับ callback `onOpenPaywall` | — |
| `App.kt` (แก้) | ส่ง `onOpenPaywall = { nav.navigate(PaywallRoute) }` ให้หน้าแรก | — |

- การนำทางไปหน้าเสี่ยงทายส่งเป็น one-shot event (`Channel` → `receiveAsFlow`) เพื่อไม่ให้หมุนจอหรือกลับมาหน้าแรกแล้วเปิดซ้ำ
- `sheet` อยู่ใน ViewModel จึงยังเปิดอยู่หลังกลับจาก paywall และสังเกต `session.status` เพื่อเปลี่ยนเป็น `READY` (หัวข้อ 3.3)
- ไม่แก้ `DivinationViewModel` หรือ `ReadingNoticeCard`

## 8. การทดสอบ

**Unit test**
- `preCastOffer`: ทุกแถวในตารางหัวข้อ 2 รวมลำดับความสำคัญ (เช่น Premium ที่ `readingsLeft = 0` ได้ `NONE`, ผู้ใช้ฟรีที่มีเหรียญได้ `NONE`, ออฟไลน์ได้ `NONE`)
- `HomeViewModel` ด้วย fake ads และ fake purchases:
  - สิทธิ์ฟรียังเหลือ → ไปหน้าเสี่ยงทายโดยไม่เปิด sheet
  - แบบโฆษณา → `Granted` → ส่ง event ไปหน้าเสี่ยงทายพร้อมคำถามเดิม
  - แบบโฆษณา → `LimitReached` → sheet กลายเป็นแบบขาย
  - แบบขาย → ซื้อเหรียญสำเร็จ → ไปหน้าเสี่ยงทาย · `Pending` → อยู่ที่ sheet พร้อมข้อความ
  - sheet เปิดอยู่แล้ว status เปลี่ยนเป็น `readingsLeft > 0` → `READY`
  - `refreshStatus` ช้าเกิน 1,500 ms → ใช้สถานะเดิม
- ข้อความแถบหน้าแรกแถวที่เปลี่ยนใน `GuidanceQuotaTest`

**บนเครื่องจริง** (บัญชีทดสอบ AdMob และ Play Billing)
1. ใช้คำทำนายฟรีของวัน → กดเริ่ม → เห็น sheet แบบโฆษณา → ชมจบ → โยนเหรียญ → ได้คำชี้แนะจากนักพรตทันที ไม่เห็นการ์ดสิทธิ์หมด
2. ทำซ้ำจนโฆษณาครบ ๒ ครั้ง → กดเริ่ม → เห็น sheet แบบขาย → ซื้อเหรียญ → ได้คำชี้แนะ เหรียญเหลือ ๙
3. sheet แบบขาย → เปิด paywall → สมัครแบบทดลอง → กลับมาเห็น "พร้อมรับคำชี้แนะแล้ว" → เริ่ม → ได้คำชี้แนะ
4. ปิดเน็ต → กดเริ่ม → เสี่ยงทายในเครื่องได้ทันทีโดยไม่ค้างที่ปุ่มเกิน ~1.5 วินาที
5. sheet แบบโฆษณา → อ่านตัวบทอย่างเดียว → การ์ดหลังเสี่ยงทายยังมีปุ่มชมโฆษณาเหมือนเดิม
