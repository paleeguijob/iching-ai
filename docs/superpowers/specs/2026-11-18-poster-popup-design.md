# อี้จิง AI — โปสเตอร์ popup และการ์ดโปรท้ายหน้ากวาประจำวัน

18 พ.ย. 2026 · แทนที่ [การ์ดโปรบนหน้าแรก](2026-11-17-home-promo-card-design.md) บน branch `feature/v1.4-siamsi` (ยังไม่ merge และยังไม่ deploy จึงเปลี่ยนรูปแบบค่าตั้งได้เต็มที่)

## 1. ทำไม

การ์ดโปรบนหน้าแรกถูกแถบถามด้านล่างบังบนจอเล็ก (Samsung A05 เห็นแค่ครึ่งบน) และเจ้าของแอปอยากได้ช่องประกาศที่ใช้ภาพ artwork ได้ ไม่ใช่แค่ข้อความ

ใช้กับ 3 เรื่อง:

| เรื่อง | ใครเห็น | กดภาพแล้ว | การ์ดเล็ก |
|---|---|---|---|
| โปรลดราคา | เฉพาะคนที่ยังไม่ใช่ Premium | หน้าจ่ายเงิน | มี |
| feature ใหม่ | ทุกคน | หน้าของ feature นั้น | ไม่จำเป็น |
| วันสำคัญ (artwork) | ทุกคน | ไม่ไปไหน ปิดอย่างเดียว | ไม่มี |

**สำเร็จเมื่อ:** เปิดประกาศได้จาก Firestore + ภาพบน Hosting โดยไม่ต้องออกแอปใหม่ · ทุกขนาดจอเห็นครบ · หน้าแรกกลับไปโล่งแบบ E

**ห้ามเกิด (anti-goals):** เด้งทุกครั้งที่เปิดแอป · เด้งใส่คนที่เพิ่งติดตั้ง · เด้งกรอบว่างตอนภาพยังไม่มา · ลิงก์พาออกนอกแอป · โปรลดราคาขึ้นให้คนที่จ่ายแล้ว

## 2. แนวทางที่พิจารณา

1. **โปสเตอร์เดียวต่อช่วงเวลา ขยายจากโปรเดิม — เลือกแบบนี้** ใช้ระบบจำ id, การกรองบน server และ log ต่อจากของเดิมได้ ข้อจำกัด: ช่วงเวลาหนึ่งมีได้ตัวเดียว ถ้าวันสำคัญชนกับโปร ต้องเลือกอย่างเดียว
2. แยก popup กับการ์ดเป็นสองค่า (เช่น popup ตรุษจีน + การ์ดขายโปรพร้อมกัน) — **ทำในอนาคต** เมื่อเริ่มมีประกาศชนกันจริง รูปแบบค่าตั้งในข้อ 3 ออกแบบให้แยก `card` ออกไปเป็นค่าของตัวเองได้โดยไม่ต้องรื้อ
3. คอลเลกชันโปสเตอร์เรียงคิว — เกินจำเป็นตอนนี้

เจ้าของแอปเลือกแบบ 1 และขอให้บันทึกไว้ว่าจะทำแบบ 2 ในอนาคต

## 3. ค่าตั้งบน server

`config/runtime.poster` ใน Firestore แทน `promo` เดิม (ลบ `promo` ทั้งฝั่ง server และแอป) อ่านด้วย `parsePoster` ใน `core/poster.ts` ผิดรูปแบบ = ไม่มีโปสเตอร์ และ log `poster_invalid` (แทน `promo_invalid`)

| ฟิลด์ | ชนิด | ตัวอย่าง | ความหมาย |
|---|---|---|---|
| `id` | string ไม่ว่าง ไม่มีช่องว่าง/ขึ้นบรรทัด | `"cny-2027"` | key ของการจำและ analytics · เปลี่ยน id = ประกาศใหม่ |
| `enabled` | boolean | `true` | สวิตช์ปิดทันที |
| `startsAt` / `endsAt` | ISO string, `endsAt > startsAt` | `2027-02-05T00:00+07:00` | ช่วงเวลา |
| `image` | path ใต้ `content/posters/` ลงท้าย `.webp` `.png` `.jpg` | `"cny-2027.webp"` | ภาพบน Hosting |
| `alt` | string ไม่ว่าง ≤ 120 | `"ตรุษจีน ๒๕๗๐ ขอให้ร่ำรวย"` | ให้ TalkBack อ่าน |
| `audience` | `"free"` หรือ `"all"` | `"free"` | `free` = ไม่ส่งให้ Premium |
| `link` | ไม่ใส่ หรือหนึ่งใน `paywall` `daily` `year` `library` `journal` | `"paywall"` | กดภาพแล้วไปไหน |
| `card` | ไม่ใส่ หรือ `{label ≤20, title ≤40, cta ≤12, showEndDate}` | | การ์ดเล็กท้ายหน้ากวาประจำวัน |

- มี `card` แต่ไม่มี `link` = ผิดรูปแบบ (การ์ดที่กดแล้วไม่ไปไหนไม่มีประโยชน์)
- `image` ห้ามมี `..` หรือขึ้นต้นด้วย `/` หรือ `http` แอปสร้าง URL เองจาก `WEB_BASE_URL` แบบเดียวกับไฟล์เซียมซี (`{WEB_BASE_URL}/content/posters/{image}`) จึงโหลดได้เฉพาะจาก Hosting ของเรา
- ภาพ: สัดส่วน **4:5** (แนะนำ 1080×1350) WebP ไม่เกิน 400 KB ข้อความสำคัญอยู่ห่างขอบ 8% เพราะมุมภาพโค้ง

## 4. `/status`

`QuotaStatus.poster: { id, image, alt, audience, link, card, endsAt } | null` (แทน `promo`)

server ส่งเมื่อ: parse ผ่าน · `enabled` · `startsAt <= now < endsAt` · ไม่ใช่ (`audience == "free"` และผู้ใช้เป็น Premium)

## 5. ฝั่งแอป

**โมเดล:** `AccountStatus.poster: PosterStatus?` และ `PosterLink` (enum: PAYWALL, DAILY, YEAR, LIBRARY, JOURNAL) · `link` ที่แอปไม่รู้จัก (มาจาก server ใหม่กว่าแอป) = **ไม่แสดงโปสเตอร์เลย** เพราะน่าจะประกาศ feature ที่แอปเวอร์ชันนี้ยังไม่มี

**การตั้งค่าที่จำในเครื่อง:**
- `seenPosterIds` — popup ที่ขึ้นไปแล้ว (เด้งครั้งเดียวต่อ id ไม่ว่าจะปิดหรือกด) เก็บล่าสุด 20 ตัว
- `dismissedPromoIds` เดิม เปลี่ยนชื่อเป็น `dismissedPosterCardIds` — การ์ดเล็กที่กด × แล้ว (ปิด popup ไม่ทำให้การ์ดหาย การ์ดคือทางกลับไปหาประกาศ)
- `firstOpenEpochDay` — วันแรกที่เปิดแอป บันทึกตอนเปิดครั้งแรกที่ยังไม่มีค่า (เครื่องที่อัปเดตจากเวอร์ชันเก่าจะนับวันที่อัปเดต ยอมรับได้)

**popup — เด้งบนหน้าแรก เมื่อครบทุกข้อ:**
1. มีโปสเตอร์ และ id ยังไม่อยู่ใน `seenPosterIds`
2. เวลาเครื่อง < `endsAt` (ทุกโปสเตอร์) และถ้า `audience == free` ผู้ใช้ต้องไม่เป็น Premium (เช็กซ้ำในเครื่อง)
3. วันนี้ไม่ใช่ `firstOpenEpochDay`
4. วันนี้อ่านกวาประจำวันแล้ว (`streak.lastEpochDay == today`) — จึงเด้งตอนกลับจากหน้ากวาประจำวัน หรือครั้งถัดไปที่เข้าหน้าแรกวันนั้น
5. โหลดภาพสำเร็จแล้ว (โหลดล่วงหน้าตั้งแต่ได้ status) ถ้าโหลดไม่ได้ก็ไม่เด้ง ลองใหม่ครั้งถัดไปที่ได้ status

ผลของข้อ 4: คนที่ไม่เคยเปิดอ่านกวาประจำวันจะไม่เห็น popup เลย รวมถึงโปรลดราคา ตั้งใจให้เป็นแบบนี้ เพราะ popup ควรขึ้นหลังผู้ใช้ได้สิ่งที่มาหาแล้วเท่านั้น

dialog แจ้งปลดล็อกธีมและขอเปิดแจ้งเตือนอยู่บนหน้ากวาประจำวัน popup อยู่บนหน้าแรก จึงไม่ซ้อนกัน

**หน้าตา popup:** พื้นหลังมืดโปร่ง · ภาพกว้างเต็มจอลบ 48dp แต่สูงไม่เกิน 70% ของจอ (ย่อทั้งภาพตามสัดส่วน) มุมโค้ง 16dp · ปุ่ม × วงกลมเหนือมุมขวาบนของภาพ ขนาดแตะ 48dp "ปิดประกาศนี้" · แตะนอกภาพ = ปิด · กดภาพ = ไปตาม `link` (ถ้าไม่มี link ภาพกดไม่ได้) · ขึ้นแล้วบันทึกลง `seenPosterIds` ทันที

**การ์ดเล็ก — ท้ายหน้ากวาประจำวัน** ใต้ปุ่ม "อ่านต่อในคัมภีร์" หน้าตา P2 เดิม แสดงเมื่อโปสเตอร์มี `card` · กฎ Premium/เวลา เหมือนข้อ 2 · ไม่อยู่ใน `dismissedPosterCardIds` · กดการ์ด = ไปตาม `link` · ไม่ต้องรอให้ popup ขึ้นก่อน · การ์ดที่ `link == daily` ไม่แสดง เพราะจะพาไปหน้าที่อยู่แล้ว *(ผู้สร้างตัดสิน)*

**หน้าแรก:** เอาการ์ดโปรออก

**โหลดภาพ:** เพิ่ม Coil 3 (`coil-compose` + `coil-network-ktor3`) ใช้ disk cache ของ Coil

## 6. Analytics

`poster_shown` · `poster_tapped` · `poster_closed` พร้อม `poster_id` และ `surface` (`popup` หรือ `card`) แทน `promo_*` เดิม (ยังไม่เคยออกสู่ผู้ใช้)

- `poster_shown`: popup นับตอนขึ้น · การ์ดนับครั้งเดียวต่อ id ต่อการเปิดหน้า แบบเดียวกับการ์ดเดิม *(ผู้สร้างตัดสิน)*
- กดภาพ = `poster_tapped` อย่างเดียว · `poster_closed` เฉพาะกด × หรือแตะนอกภาพ *(ผู้สร้างตัดสิน)*

## 7. การทดสอบ

- **backend:** parse ครบ · ทุกฟิลด์ผิด/ขาด · `card` ไม่มี `link` · `image` เป็น URL หรือมี `..` · `audience` free กับ Premium · ช่วงเวลา · `configWarnings` → `poster_invalid`
- **แอป (pure):** ตัดสิน popup ตามเงื่อนไขข้อ 1–4 ทีละข้อ · link ที่ไม่รู้จัก · ตัดสินการ์ด · `seenPosterIds` เกิน 20
- **ViewModel:** ภาพโหลดไม่สำเร็จ = ไม่เด้ง · ปิดแล้วไม่เด้งซ้ำหลังเปิดแอปใหม่ · settings โหลดช้าไม่ทำให้เด้งซ้ำ (บทเรียนจากการ์ดเดิม)
- **บนเครื่อง:** ภาพทดสอบบน Hosting + build ชั่วคราว ตรวจบนจอเล็ก (A05) และจอใหญ่
