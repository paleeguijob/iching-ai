# v1.4 — เซียมซี (ฉบับร่าง r4)

วันที่: 2026-11-08 · สถานะ: **ร่าง รอผู้ใช้ตรวจ** · Mockup: `.superpowers/brainstorm/siamsi/siamsi-ui.html`

## เป้าหมาย

เพิ่มการเสี่ยงทายที่คนไทยคุ้นเคยที่สุด คือ **เซียมซี** เป็นวิธีที่สองต่อจากอี้จิง
**ใช้คำกลอนจากตำราเซียมซีดั้งเดิม** ให้ผู้ใช้เลือกได้หลายชุด เพื่อความน่าเชื่อถือแบบเดียวกับที่อี้จิงอิงคัมภีร์จริง
ใบเซียมซีเป็นข้อมูลที่อยู่ในแอป (ไม่เรียก AI) ต้นทุนเพิ่มจึงเป็นศูนย์ ส่วน AI ใช้เฉพาะตอนผู้ใช้กด "แปลความหมาย"

### สิ่งที่ผู้ใช้บอก
- อยากเพิ่มเซียมซีเข้ามาในแอป
- ใช้ทั้งแบบ 28 ใบ และแบบศาลเจ้าจีน (หลายชุด)
- อยากใช้ข้อมูลจากตำราโบราณ เช่น เซียมซีหลวง (สายวัดโพธิ์ 28 ใบ), เซียมซีมังกรสวรรค์ (28 ใบ), เซียมซีเจ้าแม่กวนอิม, แบบศาลเจ้าจีน 100 ใบ
- ใช้คำว่า **"แปลความหมาย"** แทน "ขยายความ"
- **เก็บขั้นเสี่ยงไม้ปัว** ไว้
- **ผู้ใช้ฟรีต้องดูโฆษณาก่อนเสี่ยงทุกครั้ง** คล้ายอี้จิง

### สมมติฐาน (แก้ได้ทุกข้อ)
1. เข้าถึงจากหน้าแรกด้วยตัวสลับ "อี้จิง · เซียมซี" ไม่เพิ่มแท็บ
2. **โควตาเสี่ยงเซียมซี** (ดูรายละเอียดข้อ 2.2):
   - ผู้ใช้ฟรี: ดูโฆษณา rewarded 1 ครั้ง → เสี่ยงได้ 1 ใบ · **1 ครั้ง/วัน รวมทุกชุด**
   - Premium: ไม่ต้องดูโฆษณา · สูงสุด 10 ครั้ง/วัน
   - **แยกจากสิทธิ์โฆษณาของอี้จิง** (`adRewardsPerDay`) — ดูโฆษณาเพื่อเซียมซีไม่กินสิทธิ์คำทำนายอี้จิง
   - เซียมซีไม่เคยใช้เหรียญ
3. "แปลความหมาย" ใช้สิทธิ์คำทำนายเดิม 1 ครั้ง ตามลำดับ สิทธิ์รายวัน → โฆษณา → เหรียญ (ผู้ใช้ฟรีจึงอาจต้องดูโฆษณาอีกครั้งเพื่อแปลความหมาย)
4. ขั้น **เสี่ยงไม้ปัวเป็นขั้นบังคับ** ไม่มีปุ่มข้ามและไม่มีตัวเลือกปิดในตั้งค่า
5. ทุกชุดฟรีเท่ากัน ไม่ขายชุดแยก (พิจารณาภายหลังได้)

### เกณฑ์ความสำเร็จ
- ผู้ใช้ใหม่เสี่ยงเซียมซีจนเห็นใบได้ใน ≤ 5 แตะหลังเปิดแอป (ไม่นับเวลาดูโฆษณา)
- ใบเซียมซีเปิดได้แม้ออฟไลน์ (ออฟไลน์ไม่มีโฆษณา → ให้เสี่ยงได้ ดู 2.2)
- รายได้โฆษณาจากเซียมซีวัดแยกได้ (`ad_placement = siamsi_draw`)
- ทุกใบระบุที่มาของตำรา และไม่มีเนื้อหาที่ติดลิขสิทธิ์ของผู้อื่น
- ≥ 25% ของ DAU เสี่ยงเซียมซีอย่างน้อย 1 ครั้ง/สัปดาห์ หลังเปิดตัว 4 สัปดาห์
- อัตรากด "แปลความหมาย" ≥ 15% ของการเสี่ยงเซียมซี

### 1.2 กติกาลิขสิทธิ์ (สำคัญ)
- **ใช้ได้:** คำกลอนต้นฉบับจากตำราโบราณที่ไม่ปรากฏผู้แต่ง (เช่น กลอนจีนของ 觀音靈籤 / 六十甲子籤)
- **ห้ามคัดลอก:** คำแปลไทย คำอธิบาย และคำทำนายรายเรื่องจากหนังสือหรือเว็บที่พิมพ์ในยุคปัจจุบัน — ส่วนนี้มักมีลิขสิทธิ์ของผู้แปล/สำนักพิมพ์ แม้คำกลอนต้นฉบับจะไม่มี
- **ดังนั้น:** คำแปลไทย, ความหมายรวม และคำทำนาย 7 เรื่อง **เขียนเองทั้งหมด** (ร่างด้วย AI ได้ แต่คนต้องตรวจทุกใบ) โดยอิงความหมายของคำกลอนต้นฉบับและเรื่องในตำนาน (典故) ที่ใบนั้นอ้างถึง
- ชื่อวัด/ศาลเจ้าใช้เพื่อระบุที่มาเท่านั้น ห้ามใช้ตรา/โลโก้ และแสดงข้อความ "ไม่ได้รับการรับรองจากวัดหรือศาลเจ้าใด"

### 1.3 ชุด 28 ใบแบบไทย — ต้องทำก่อนลงมือ
งานสำรวจพบว่าวัดไทยส่วนใหญ่ใช้ใบเซียมซี 28 ใบที่ **ซื้อจากสำนักพิมพ์ในกรุงเทพฯ** และยังไม่พบตำรา "เซียมซีหลวง วัดโพธิ์" หรือ "มังกรสวรรค์" ฉบับที่ตรวจสอบได้ จึงต้อง:
1. ผู้ใช้หาตัวเล่ม/ฉบับพิมพ์ที่ต้องการ (ชื่อเล่ม, ผู้เรียบเรียง, ปีที่พิมพ์ หรือภาพถ่ายใบจริง)
2. ตรวจลิขสิทธิ์: ถ้าเป็นงานที่มีผู้แต่ง/สำนักพิมพ์และยังไม่หมดอายุคุ้มครอง → ต้องขออนุญาตเป็นลายลักษณ์อักษร หรือไม่ใช้
3. ถ้าใช้ไม่ได้ → **ทางสำรอง:** แต่งชุด 28 ใบใหม่ในขนบกลอนเซียมซีไทย และตั้งชื่อชุดโดยไม่อ้างวัด (เช่น "เซียมซีไทย ๒๘ ใบ")

**ลำดับปล่อย:** v1.4 เปิดด้วย `guanyin100` + `jiazi60` · ชุด 28 ใบตามมาเมื่อผ่านข้อ 1.3 (เพิ่มชุดได้โดยไม่อัปเดตแอป ดู 3)

### 1.4 โครงสร้างข้อมูล
ไฟล์ละชุด `docs/content/siamsi/{setId}.json`

```json
{
  "id": "guanyin100",
  "name": "เซียมซีเจ้าแม่กวนอิม",
  "count": 100,
  "source": { "title": "觀音靈籤", "note": "ตำราโบราณ ไม่ปรากฏผู้แต่ง · คำแปลและคำอธิบายโดยทีมอี้จิง AI" },
  "sticks": [{
    "number": 17,
    "grade_orig": "中吉",                  // เกรดตามตำรา (ถ้ามี) เช่น 上上 / 中平 / 下下
    "level": "good",                       // excellent | good | fair | caution (map จาก grade_orig)
    "label_orig": null,                    // jiazi60: คู่ก้านกิ่ง เช่น "甲子"
    "poem_orig": ["…", "…", "…", "…"],     // กลอนต้นฉบับ (จีน / ไทย)
    "poem_th": ["…", "…", "…", "…"],       // คำแปลไทยของเรา (ชุดไทยใช้ = poem_orig)
    "story": "เรื่องในตำนานที่ใบอ้างถึง (เขียนเอง)",
    "summary": "ความหมายรวม 1 ย่อหน้า",
    "topics": { "work": "…", "money": "…", "love": "…", "health": "…", "travel": "…", "lost": "…", "dealings": "…" },
    "keywords": ["…"]
  }]
}
```

- map เกรด: 上上 → ดีมาก · 上 / 上吉 / 大吉 → ดี · 中 / 中吉 / 中平 → ปานกลาง · 下 / 下下 → ควรระวัง
- ใบ "ควรระวัง" เขียนเป็นคำเตือนเชิงสร้างสรรค์ ไม่ฟันธงเรื่องร้าย
- เรื่องสุขภาพ **ห้ามแนะนำการรักษา** ให้เขียนแนว "ดูแลตัวเอง ปรึกษาแพทย์เมื่อมีอาการ"
- v2 ภาษาอังกฤษ/จีน: เพิ่ม `poem_en`, `summary_en` ฯลฯ

## 2 · ผู้ใช้เห็นอะไร (Flow)

```
หน้าแรก [อี้จิง | เซียมซี●] · ชุด: เจ้าแม่กวนอิม ๑๐๐ ใบ ▾
  → ตั้งจิต (คำถามไม่บังคับ + หมวด) → [ดูโฆษณา] (ผู้ใช้ฟรี) → เขย่ากระบอก → ไม้ตก "ใบที่ ๑๗"
  → เสี่ยงไม้ปัว (บังคับ · ศักดิ์ = ยืนยัน, สูงสุด 3 รอบ) → ใบเซียมซี (ข้อมูลในแอป)
  → [แปลความหมาย] (AI, ใช้สิทธิ์) · แชร์ · บันทึก
```

### 2.1 หน้าแรก + เลือกชุด
- ตัวสลับ `ZenSegmented` ใต้การ์ดกวาประจำวัน จำค่าล่าสุด
- เมื่อเลือกเซียมซี: แถว "ชุด · เจ้าแม่กวนอิม ๑๐๐ ใบ ›" แตะแล้วเปิด bottom sheet `SiamSiSetSheet`
  - รายการชุดเป็น `ZenCard` แถวคั่นเส้น: ชื่อชุด · จำนวนใบ · ที่มาหนึ่งบรรทัด · วงชาดที่ชุดที่เลือก
  - ชุดที่ยังไม่พร้อม (config ปิด) ไม่แสดง
- หัวข้อ Charm "อธิษฐานแล้วเสี่ยงเซียมซี" · ช่องคำถาม (ไม่บังคับ) · ชิปหมวดเดิม
- บรรทัดโควตา + ปุ่มหลักตามสถานะ (ข้อ 2.2)

### 2.2 ดูโฆษณาก่อนเสี่ยง (`SiamSiDrawGate`)

ใช้ `bridges.ads.showRewarded` และ pattern เดียวกับ `AppSession` ของอี้จิง แต่ **นับสิทธิ์ฝั่ง client** เพราะใบเซียมซีไม่มีต้นทุน server

| สถานะ | บรรทัดโควตา | ปุ่มหลัก | กดแล้ว |
|---|---|---|---|
| ฟรี, เหลือสิทธิ์ | "ดูโฆษณาสั้น ๆ ก่อนเสี่ยง · วันนี้เหลือ ๑ ครั้ง" | "▶ ดูโฆษณาแล้วเขย่าเซียมซี" | เล่นโฆษณา → ได้ `rewarded` → เข้าหน้าเขย่า |
| ฟรี, ปิดโฆษณากลางคัน | "ต้องดูโฆษณาจนจบจึงจะเสี่ยงได้" | เหมือนเดิม | ไม่นับสิทธิ์ |
| ฟรี, โฆษณาโหลดไม่ได้ / ออฟไลน์ | "ยังไม่มีโฆษณาในตอนนี้ เสี่ยงได้เลย" | "เขย่าเซียมซี" | เข้าหน้าเขย่า **นับสิทธิ์** (ไม่ให้ผู้ใช้ติดเพราะ no-fill) · log `siamsi_ad_unavailable` |
| ฟรี, ใช้สิทธิ์ของวันแล้ว | "วันนี้เสี่ยงครบแล้ว กลับมาใหม่พรุ่งนี้" | "สมัคร Premium เสี่ยงได้ ๑๐ ครั้ง/วัน ไม่มีโฆษณา" | เปิด Paywall |
| Premium, เหลือสิทธิ์ | "วันนี้เหลือ ๑๐ ครั้ง" | "เขย่าเซียมซี" | เข้าหน้าเขย่าทันที |
| Premium, ครบ 10 ครั้ง | "วันนี้เสี่ยงครบแล้ว กลับมาใหม่พรุ่งนี้" | ปิดปุ่ม | — |

- **1 สิทธิ์ = 1 ใบที่ได้** นับตอนดูโฆษณาจบ (หรือตอนเข้าหน้าเขย่าถ้าไม่มีโฆษณา) — เขย่าใหม่เพราะไม้ปัวไม่ผ่าน **ไม่ต้องดูโฆษณาซ้ำ**
- ออกจากหน้าเขย่าก่อนได้ใบ → สิทธิ์ที่ได้จากโฆษณายังค้างไว้ใช้ได้ถึงสิ้นวัน (`pendingDraw`) ไม่ต้องดูโฆษณาใหม่
- โฆษณาอยู่ **ก่อน** การเขย่า ไม่คั่นระหว่างเขย่า/ปัว/เปิดใบ เพื่อไม่ทำลายจังหวะพิธี

### 2.3 เขย่ากระบอก (`SiamSiShakeScreen`)
- กระบอกไม้ไผ่ติดอักษร 籤 · ไม้ขยับตามการเขย่าเครื่อง (accelerometer) หรือ **กดค้าง**
- haptic + เสียงไม้กระทบ (ตามการตั้งค่าเสียงเดิม)
- หลังเขย่าสะสม ~1.5 วินาที ไม้ 1 อันตกออกมา แสดงเลขไทยตัวใหญ่สีชาด
- เลขถูกสุ่ม **ก่อน** แอนิเมชันด้วย `SecureRandom` uniform 1–`count` ของชุด

### 2.4 เสี่ยงไม้ปัว (`PuaStage`) — ขั้นบังคับ
- หลังไม้ตก ปุ่มหลักเดียวคือ "เสี่ยงไม้ปัวยืนยัน" ไม่มีปุ่มข้าม
- **ศักดิ์** (คว่ำ-หงาย) 50% = ยืนยัน · **หัวเราะ** (หงาย-หงาย) 25% · **ไม่** (คว่ำ-คว่ำ) 25% → เขย่าใหม่
- รอบที่ 3 ที่ยังไม่ได้ศักดิ์ → ยืนยันใบล่าสุดอัตโนมัติ "ฟ้ายอมให้ใบนี้"
- เขย่าใหม่เพราะปัวไม่ผ่าน **ไม่นับโควตาและไม่ต้องดูโฆษณาซ้ำ**

### 2.5 ใบเซียมซี (`SiamSiSlipScreen`)
- `ZenCard(accentTop = true)`:
  - ป้าย "เซียมซีเจ้าแม่กวนอิม · ใบที่ ๑๗" + ป้ายระดับ (และเกรดตามตำรา เช่น 中吉 ตัวเล็ก)
  - ชุดจีน: กลอนต้นฉบับ (`Noto Serif TC`) แล้วตามด้วยคำแปลไทย · ชุดไทย: กลอนไทยอย่างเดียว
  - jiazi60: แสดงคู่ก้านกิ่ง (甲子) ใต้เลขใบ
  - "เรื่องในตำนาน" พับ/ขยายได้ · ความหมายรวม
- การ์ด "แปลความหมาย" (2.6)
- การ์ดคำทำนาย 7 เรื่อง: การงาน · การเงิน · ความรัก · สุขภาพ · การเดินทาง · ของหาย · คดีความ/การติดต่อ — เรื่องที่ตรงหมวดที่เลือกขึ้นบนสุด มีจุดชาด
- ท้ายหน้า: ที่มา "ตำรา 觀音靈籤 · คำแปลโดยทีมอี้จิง AI · ไม่ได้รับการรับรองจากวัดหรือศาลเจ้าใด" + "เซียมซีเพื่อการไตร่ตรองและความบันเทิง โปรดใช้วิจารณญาณ"

### 2.6 แปลความหมาย (AI)
- ปุ่มในการ์ด: "ให้นักพรตแปลความหมายตามคำถามของคุณ · ใช้ ๑ สิทธิ์" · ปุ่ม "แปลความหมาย"
- สิทธิ์หมด → ข้อเสนอเดิม (Premium / เหรียญ / โฆษณา) จาก precast offer
- ผลเป็นแผ่นกระดาษเรียบ หัวการ์ด "คำแปลจากนักพรต" + ป้าย "AI" พิมพ์ทีละตัว (Typewriter เดิม)
- Premium ถามต่อได้ตามกติกา follow-up เดิม

### 2.7 บันทึกชะตา / แชร์
- แถว: "เซียมซีกวนอิม ใบที่ ๑๗ · ดี · มีคำแปล" + ไอคอนไม้เซียมซีแทนรูปกวา
- ชิปกรอง "ทั้งหมด · อี้จิง · เซียมซี"
- การ์ดแชร์: ชื่อชุด, เลข, ระดับ, กลอน + ที่มา บนพื้น `InkPaperPalette` — **ไม่แชร์คำถามของผู้ใช้**

## 4 · Server

**Endpoint ใหม่:** `POST /siamsi/interpret` ตอบเป็น stream แบบเดียวกับ `/divine`

| ลำดับ | การทำงาน |
|---|---|
| 1 | รับ `{ set, stick, question?, category? }` · ชุดไม่อยู่ใน `siamsiSets` หรือ stick นอก 1–`count` → `400` |
| 2 | ตรวจ `siamsiEnabled` และ `aiEnabled` → ไม่ผ่าน `503` |
| 3 | ตัดสิทธิ์ตามลำดับเดิม ใช้ฟังก์ชันเดียวกับ `/divine` |
| 4 | `buildSiamSiPrompt` ใส่ใบจาก `functions/data/siamsi/{set}.json` (ไม่เชื่อข้อความใบจาก client) |
| 5 | สำเร็จ → บันทึก reading `method: "siamsi"`, `set`, `stick`, `text`, `model` |
| 6 | ล้มเหลว / safety filter → refund ด้วยตรรกะเดิม |

- ใช้ `minSecondsBetweenReadings`, rate limit, App Check ร่วมกับ `/divine`
- Prompt: persona นักพรตเดิม + กฎ "แปลความหมายจากกลอนและเรื่องในตำนานของใบนี้เข้ากับคำถาม ห้ามขัดระดับของใบ ห้ามแต่งกลอนใหม่หรืออ้างว่าเป็นคำของวัด ห้ามทำนายเรื่องความตาย/โรคร้าย" + `SUMMARY_RULE` เดิม
- โมเดลตาม tier เหมือนคำทำนายปกติ · ใช้ context caching กับ system instruction
- ใบที่ไม่ขอแปลความหมาย **ไม่ส่งขึ้น server** — เก็บใน Journal ฝั่ง local และ sync ตามกลไกเดิม

**RuntimeConfig ใหม่**

| ฟิลด์ | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| `siamsiEnabled` | `false` | สวิตช์ฟีเจอร์ |
| `siamsiSets` | `["guanyin100","jiazi60"]` | ชุดที่เปิดให้ใช้ + `version` ของแต่ละชุด |
| `siamsiAdDrawsPerDay` | `1` | เพดานผู้ใช้ฟรี (ดูโฆษณา 1 ครั้ง = 1 ใบ) · ส่งผ่าน `GET /status` |
| `siamsiPremiumPerDay` | `10` | เพดาน Premium · ส่งผ่าน `GET /status` |

- โควตาเซียมซีนับฝั่ง client เท่านั้น server ไม่บันทึก (ไม่มีต้นทุนให้ป้องกัน) · ไม่ยุ่งกับ `adRewardsPerDay`, `adEarned`, `adUsed` ของอี้จิง

## 5 · ต้นทุน
- ใบเซียมซี: 0 บาท (ไฟล์ทุกชุดรวม < 1 MB) และ **ได้รายได้โฆษณา** 1 ครั้ง/ผู้ใช้ฟรี/วัน
- แปลความหมาย: เท่าคำทำนายอี้จิง 1 ครั้ง (~0.02–0.09 บาท) และแข่งกับโควตาเดิม — ไม่เพิ่มต้นทุนต่อผู้ใช้
- งานเนื้อหา: แปลและเขียนคำอธิบาย 160 ใบ (100 + 60) คืองานใหญ่ที่สุดของเวอร์ชันนี้

## 9 · การทดสอบ
- Unit (`core/domain`): `drawStick` ได้ครบ 1–`count` สำหรับ 28/60/100 และกระจายใกล้ uniform (chi-square, seed คงที่) · `tossPua` 50/25/25 · รอบที่ 3 ยืนยันอัตโนมัติ · ปัวไม่ผ่านไม่นับโควตา · `gradeToLevel` ครบทุกเกรด
- Content test ทุกไฟล์ชุด: จำนวนใบ = `count`, เลขไม่ซ้ำ, กลอน 4 วรรคทั้ง `poem_orig` และ `poem_th`, ครบ 7 topics, มี `source`
- `SiamSiQuota`: รวมทุกชุด, รีเซ็ตเที่ยงคืน UTC+7, เพดานฟรี 1 / Premium 10, `pendingDraw` ค้างถึงสิ้นวัน
- `SiamSiDrawGate` (ใช้ fake `AdsBridge` แบบ `AppSessionTest`): ทุกแถวในตาราง 2.2 — rewarded → เข้าหน้าเขย่า · dismissed → ไม่นับ · unavailable → เสี่ยงได้และนับ · ครบเพดาน → Paywall · Premium ไม่เรียกโฆษณา · ปัวไม่ผ่านไม่เรียกโฆษณาซ้ำ · ไม่แตะ `adEarned` ของอี้จิง
- `SiamSiRepository`: ชุดดาวน์โหลดเสีย/ไม่ครบ → ไม่แสดงชุดนั้น ไม่ crash
- Backend: `/siamsi/interpret` ตัด/คืนสิทธิ์, ปฏิเสธชุด/เลขผิด, ไม่ใช้ข้อความใบจาก client, `siamsiEnabled=false` → 503
- ตรวจด้วยตาทั้ง 5 ธีม: หน้าแรก+เลือกชุด, เขย่า, ปัว, ใบเซียมซี (จีน/ไทย), แปลความหมาย, Journal
