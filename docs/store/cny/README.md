# ชุด listing ตรุษจีน ๒๕๗๐ (v1.2)

ใช้ช่วง 20 ม.ค. – 22 ก.พ. 2027 · หลัง `endsAt` ให้เปลี่ยน listing กลับเป็นชุดเดิม (ดู `docs/RELEASE.md` หัวข้อ 12)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `feature-graphic-1024x500.svg` | ต้นฉบับ feature graphic แดงทอง (วาดเอง ไม่มีภาพหรือฟอนต์ที่ต้องมีสิทธิ์) |
| `feature-graphic-1024x500.png` | ภาพ 1024×500 พร้อมอัปโหลดที่ Play Console → Store listing → Feature graphic |

เรนเดอร์ PNG ใหม่หลังแก้ SVG: Chrome headless
`chrome --headless=new --hide-scrollbars --window-size=1024,500 --screenshot=feature-graphic-1024x500.png file://<path>/feature-graphic-1024x500.svg`

## Screenshot ที่เจ้าของต้องถ่ายเอง (ต้องใช้เครื่องจริง/emulator ที่ตั้ง `startsAt` เป็นตอนนี้)

วางเป็นภาพที่ 1–2 ของ listing และเก็บไฟล์ไว้ในโฟลเดอร์นี้ (ชื่อ `01-home-campaign-card.png`, `02-year-screen.png`) ตามสเปกข้อ 7

1. `01-home-campaign-card.png` — หน้าแรกที่มีการ์ดแคมเปญอยู่ด้านบน
2. `02-year-screen.png` — หน้ากวาประจำปี หลังเสี่ยงทายแล้ว (เห็นกวา ข้อความภาพรวม และธีมชาดทอง)

ถ่ายด้วยจอ 1080×1920 หรือใกล้เคียง · ห้ามมีข้อมูลส่วนตัวหรือบัญชีผู้ใช้จริงในภาพ

## ข้อความ listing

- คำอธิบายสั้นช่วงแคมเปญ (≤ 80 ตัวอักษร): `เสี่ยงทายกวาประจำปีมะแม ๒๕๗๐ ฟรี · คำทำนายอี้จิงจากนักพรต`
- คำค้นที่ต้องสอดลงในคำอธิบายเต็ม/สั้น (Play Console ไม่มีช่องคำค้น): `ดวงตรุษจีน`, `ดวงปีมะแม 2570`, `เสี่ยงทายปีใหม่`, `ดวงปีใหม่จีน`
- Promotional content (LiveOps): สร้างได้ถ้าบัญชีมีสิทธิ์ · ถ้าไม่มี ข้ามได้
