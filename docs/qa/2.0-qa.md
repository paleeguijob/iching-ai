# 2.0 acceptance QA (Task 17)

Date 2026-11-21. Build: debug APK of the merged tree (02d0698, versionName 2.0.0) on emulator-5554 (Pixel_10_Pro_XL, `wm size 1080x2400` = 360dp), pointed at the local Firebase emulators (auth, functions, firestore) via a cleartext init script kept outside the repo. Evidence is in `.superpowers/sdd/2026-11-20-v2.0-english-widget/` (git-ignored): `qa-th/` (Thai re-shoot), `qa-en/` (English, all themes, widget, flows), baseline in `baseline-th/`.

Method notes: the emulator image cannot set the clock from adb (no root), so clock changes went through Settings > Date & time (auto time off, restored to auto afterwards; clock now matches the host). The four non-default themes are locked behind streak days, so the unlocked-themes and selected-theme keys in the app's own debug DataStore were edited with `run-as` (debug build, emulator only) to shoot them. Everything that needs the real API from the app is blocked, see Step 2 and "Blocked by App Check".

## Blocked by App Check (still true)
The debug App Check token for the emulator is not registered, and in addition the app signs in with the production Firebase Auth project while the functions emulator verifies ID tokens against the Auth emulator, so even with App Check solved the app could not talk to the local backend. Not reachable from the app: AI reading, follow-up, Siam Si (flag never loads), saving to the journal from the server, yearly hexagram, quota/status poster, paywall prices. Readings made in the app fall back to the on-device scripture text ("There is no internet connection...").
